# 16_geometry_realistic_samples 样本生成改进记录

本实验从 `15_bspline_wavelet_bank` 复制而来，当前只修改样本生成部分，网络、训练、推理代码结构暂时保留。

## 修改目标

解决 15 号实验中三井、四井合成剖面 `wide label` 高频不足的问题。15 号中三井/四井剖面经过克里金和平滑后，高频比例没有明显高于低通输入。

## 当前修改

1. 井位置按实际 F3 crossline 投影。
   - 使用 `data/well_trace_matches.npy` 中的井旁道匹配结果。
   - 横向位置为 `well_crossline - 300`。
   - 井不再强制放在剖面左右边界，井外侧保留地震道范围。

2. 多井反射系数剖面改为线性插值。
   - 二井、三井、四井全部按实际 crossline 排序。
   - 每个时间采样点沿横向做线性插值。
   - 井外侧用边界井值延拓。

3. 去除 Q 滤波。
   - `USE_Q_FILTER = False`。
   - 保留配置参数，但本轮样本生成不对 `clean_wide` 和 `clean_narrow` 做 Q 衰减。

4. 构造扰动只在中下部增强。
   - `STRUCTURE_START_SAMPLE = 120`。
   - `STRUCTURE_FULL_SAMPLE = 240`。
   - 浅部基本保持平行同相轴。

5. 最近邻位移改为线性插值。
   - 不再使用 `np.rint(sample_pos)`。
   - 每道使用 `np.interp` 沿时间方向重采样。
   - 横向平滑使用 `uniform_filter1d(..., size=5, axis=1)`。

6. 断层改为带倾角的局部断层。
   - 断层线为 `fault_x(t) = x0 + dip * (t - t0)`。
   - 仅在中下部生效。

## 生成结果

- 剖面数：33。
- patch 数：1980。
- train/val：1584/396。
- 插值方式：`actual_crossline_linear`。
- Q 滤波：关闭。
- 子波：只使用三个 B 样条宽频子波。

## 高频验证

合成剖面频谱输出位于：

- `figures/合成剖面/2well_synthetic_spectra.png`
- `figures/合成剖面/3well_synthetic_spectra.png`
- `figures/合成剖面/4well_synthetic_spectra.png`
- `figures/合成剖面/synthetic_section_spectra_compare.png`
- `figures/合成剖面/synthetic_section_spectra_stats.csv`

关键频谱结果：

| 类型 | lowpass 35-80 ratio | wide 35-80 ratio | residual 35-80 ratio |
| --- | ---: | ---: | ---: |
| 2well | 0.1250 | 0.5135 | 0.7354 |
| 3well | 0.0902 | 0.4983 | 0.7431 |
| 4well | 0.0969 | 0.5092 | 0.7210 |

结论：16 号样本生成后，三井和四井的 `wide label` 高频比例已经明显高于低通输入，样本频带问题相比 15 号有明显改善。
