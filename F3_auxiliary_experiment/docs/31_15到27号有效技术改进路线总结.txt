15号到27号有效技术改进路线总结

说明：19号到24号实验属于无效探索过程，相关实验文件夹和文档已删除。本文件只保留目前确认有意义、需要继续沿用的技术改进。

一、最开始的偏置修正方案

关键目的：
修正预测结果中存在的整体振幅/均值偏置，避免网络输出在低频主体之外引入不合理的整体漂移。

关键做法：
1. 不再直接信任网络输出的绝对幅值偏置。
2. 将最终结果的低频主体固定为低通输入数据。
3. 网络只负责补充高频或中高频残差信息。
4. 最终结果通过“低通输入 + 预测残差”得到，减少整体相位和振幅主体被破坏的风险。

保留原因：
该方案明确了拓频结果不能脱离原始窄频数据主体，后续所有残差预测实验都应继承这个思想。


二、从宽频预测转向高频残差预测

关键目的：
避免网络直接重建完整宽频剖面时破坏低频结构、相位和连续同相轴。

关键做法：
1. 网络输入为低通/窄频剖面。
2. 标签由完整宽频剖面改为：

   residual_label = clean_wide - clean_narrow

3. 网络输出为高频残差，而不是完整宽频。
4. 推理阶段最终结果为：

   final_prediction = narrow_raw + residual_pred

5. 必要时再对预测残差进行高通滤波后与低通输入重组。

保留原因：
宽频直预测虽然可以改善频谱距离，但容易降低空间相关性和相位一致性；残差预测更符合“保护已有低频、只补缺失频带”的目标。


三、正确的SEG-Y数据读取

关键目的：
解决F3工区不同inline/crossline尺寸不一致导致的剖面拼接错误，避免一个剖面实际由两个剖面的局部片段组成。

关键做法：
1. 不再按固定二维尺寸粗暴reshape SEG-Y数据。
2. 根据SEG-Y道头中的inline、crossline信息组织三维数据。
3. 读取inline或crossline剖面时，按真实道号索引提取。
4. 测井数据与井旁地震道重新基于修正后的地震坐标匹配。
5. 后续样本生成、推理和评价都必须使用该读取方式。

保留原因：
这是数据基础问题。若地震剖面读取错误，后续子波估计、样本生成、训练标签和评价结果都会失真。


四、F3风格统计迁移合成样本

关键目的：
缩小纯测井合成样本与F3实际剖面之间的域差异，同时避免直接使用F3宽频数据作为训练目标造成数据泄露。

关键做法：
1. 不把F3真实宽频数据用于训练标签。
2. 不直接把F3低通剖面作为训练输入-标签配对。
3. 只从F3低通剖面中提取统计风格信息，例如：
   - 横向相邻道相关性；
   - 局部相干性；
   - gx/gt梯度分布；
   - 同相轴连续性；
   - 中深部小错断形态；
   - 弱反射背景和噪声水平。
4. 在测井/子波控制的合成剖面中迁移这些统计特征。
5. 合成样本中加入：
   - 中深部褶皱和局部隆起；
   - 倾斜断层，而不是竖直错断；
   - 采样点300以下的小错断；
   - 局部振幅衰减和相位扰动；
   - 更强横向连续性和更低随机纹理强度。
6. 使用线性插值做时间位移，避免最近邻采样导致同相轴跳动。

保留原因：
这是目前最有价值的样本改进方向。它不直接泄露F3宽频目标，同时能让合成样本更接近实际F3低通剖面的构造和纹理统计。


五、归一化标准确定为clean_narrow的P99

关键目的：
统一训练和推理阶段的幅值尺度，避免标签、输入和实际推理数据使用不同归一化标准导致网络输出幅值失控。

关键做法：
1. 每个合成样本按clean_narrow的99百分位绝对值计算共享尺度：

   shared_scale = percentile(abs(clean_narrow), 99)

2. 训练输入：

   clean_input_norm = clean_narrow / shared_scale
   input_norm = clean_input_norm + noise

3. 训练标签：

   wide_norm = clean_wide / shared_scale
   label_norm = wide_norm - clean_input_norm

4. 标签不含噪声，噪声只加到输入。
5. 推理阶段对实际低通输入同样使用其P99绝对值归一化。
6. 网络输出残差后，再乘回推理输入的P99尺度。
7. 不再使用R_MEDIAN，也不使用全局宽/窄频振幅比例强行放大最终结果。

保留原因：
该标准保证训练输入、训练标签和实际推理输入处于同一幅值体系，是残差预测稳定性的基础。


当前后续实验应遵守的核心闭环

clean_wide -> lowpass(clean_wide) = clean_narrow

model_input = clean_narrow / P99(clean_narrow) + input_noise

residual_label = clean_wide / P99(clean_narrow) - clean_narrow / P99(clean_narrow)

residual_pred = model(model_input)

final_prediction = narrow_raw + residual_pred * P99(narrow_raw)


当前判断

后续实验不应继续沿用19号到24号的路线。有效路线应回到“正确SEG-Y读取 + clean_narrow P99归一化 + F3风格统计迁移合成样本 + 高频残差预测 + 低频主体保护”的技术框架。
