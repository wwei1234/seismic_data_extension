26号实验：F3-style 合成样本的宽频直预测版本

一、改进目的
25号实验使用 F3-style 合成剖面训练高频残差标签，推理时采用“低通输入 + 预测残差”的重组方式。25号结果显示预测残差偏弱、偏稀疏，残差相位和实际高频残差的相关性不稳定。

26号实验在保持25号合成剖面生成方式不变的前提下，只改变标签设计：训练标签由高频残差改为完整宽频数据，让网络直接学习“低通输入 -> 宽频输出”的映射。

二、样本生成
1. 样本来源仍为25号的 F3-style 合成剖面生成逻辑。
2. 实际 F3 宽频数据不参与训练标签构建，只用于推理后的评价。
3. F3低通剖面只作为统计风格参考，用于约束合成剖面的横向连续性、梯度、局部纹理和小错断特征。
4. 输入数据为合成宽频剖面的 0-35 Hz 低通结果。
5. 标签数据为同一合成剖面的宽频结果。
6. 输入端添加噪声水平为 0.01 和 0.03，标签端不加噪声。
7. 每个剖面按 256x256 patch 切片，步长 128。
8. 数据增强只使用左右翻转，不使用上下翻转。

三、标签定义
25号：
label = wide_norm - clean_input_norm

26号：
label = wide_norm

归一化仍使用每个合成剖面的 clean_narrow 绝对值 P99：
shared_scale = P99(abs(clean_narrow))
clean_input_norm = clean_narrow / shared_scale
wide_norm = clean_wide / shared_scale

四、训练设置
训练模型沿用宽频直预测框架，网络结构不变，损失函数由波形 L1、频谱幅值、相位、梯度和低频一致性组成。

训练轮数：200
patch数量：1386
训练集：1109
验证集：277
最佳验证损失：0.157220
最佳轮次：197

五、评价方式
使用训练完成的 best_model.pth 对四口井所在 inline 和 crossline 剖面分别进行预测。

推理过程：
1. 从实际 F3 宽频数据生成 0-35 Hz 低通输入。
2. 用模型直接输出归一化宽频预测。
3. 用当前低通剖面的 P99 尺度反归一化。
4. 将预测宽频结果与实际 F3 宽频参考剖面对比。

六、主要结果
inline 四剖面：
低通输入相关性 0.631007，RMSE 1841.364378，频谱L1 0.325115。
宽频直预测相关性 0.592715，RMSE 1911.599931，频谱L1 0.216701。

crossline 四剖面：
低通输入相关性 0.606427，RMSE 1916.920426，频谱L1 0.362238。
宽频直预测相关性 0.576220，RMSE 1969.968200，频谱L1 0.249462。

七、结论
26号实验相对低通输入明显改善了频谱匹配，35-90 Hz 高频能量被补偿出来，说明宽频直预测比25号残差预测更容易输出连续的宽频能量。

但空间域指标仍下降：相关性降低，RMSE升高。这说明 direct-wide 标签会让网络更积极地生成高频，但当前合成样本与真实 F3 宽频之间仍存在相位、振幅和局部反射细节差异。该方案在频谱拓展上有效，但还没有解决相位保护和实际同相轴精确对齐问题。

下一步建议：
1. 不建议直接把26号作为最终方案。
2. 可以保留宽频直预测思路，但需要加入低频一致性硬约束或输出后低频替换，即最终结果的 0-35 Hz 严格取自输入低通，只让模型负责 35 Hz 以上补偿。
3. 继续提高合成样本与实际 F3 的局部相位统计一致性，尤其是深部小错断附近的相位扰动、振幅衰减和横向相干性。
4. 可尝试混合目标：网络输出宽频，但损失中加强 residual/high-band 相位约束，同时低频部分强制等于输入。
