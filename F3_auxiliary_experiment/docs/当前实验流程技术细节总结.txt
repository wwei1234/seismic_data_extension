实验流程技术细节总结

================================================================================
一、实验总体定位
================================================================================

1. 当前实验属于 F3 辅助拓频实验。

2. 核心任务：
   低通地震数据 → 预测高频残差 → 加回低通输入 → 得到宽频预测。

3. 当前网络不是直接预测宽频地震，而是预测 residual：

       residual = wide - narrow
       wide_pred = narrow + residual_pred

4. 训练样本由合成数据生成，实际 F3 数据用于推理和评价。

5. 样本生成脚本中，train_labels / val_labels 保存的是：

       normalized wide - normalized low-pass

   即归一化空间中的高频残差标签。


================================================================================
二、基础参数配置
================================================================================

1. 当前实验目录：

       16_geometry_realistic_samples

2. 核心参数：

       DT = 0.004 s
       FS = 250 Hz
       PATCH_SIZE = 256
       PATCH_STRIDE = 256
       SYNTHETIC_SECTION_WIDTH = 951
       CROSSLINE_MIN = 300
       CROSSLINE_MAX = 1250
       NARROW_BAND = 3-6-25-35 Hz

3. 合成剖面宽度 951 道，与 F3 crossline 300-1250 对应。

================================================================================
三、输入数据来源
================================================================================

1. 使用四口井的反射系数数据：

       F02-1
       F03-2
       F03-4
       F06-1

2. 样本生成阶段读取的数据包括：

       well_reflectivities.npy
       well_trace_matches.npy
       well_estimated_wavelets.npy

3. F3 实际 SEG-Y 数据路径：

       WORKSPACE_ROOT / Rawdata / Seismic_data.sgy

4. Rawdata 文件夹放在实验根目录上一级，避免每个实验方案重复复制大体积数据。


================================================================================
四、井震匹配与估计子波生成
================================================================================

1. 井旁地震道匹配脚本：

       01_rematch_wells_estimate_wavelets.py

2. 匹配方式：

       扫描 SEG-Y trace header；
       根据井口 X/Y 坐标寻找最近的 SEG-Y trace；
       输出对应 inline、crossline、trace_index 和距离。

3. 匹配依据：

       distance = sqrt((trace_x - well_x)^2 + (trace_y - well_y)^2)

4. 输出文件包括：

       well_traces.npy
       well_trace_matches.npy
       well_wavelet_tie_scores.npy
       well_estimated_wavelets.npy
       well_wide_wavelets.npy
       well_narrow_wavelets.npy
       well_wavelet_pairs.npy

5. 估计子波方法为频率域反褶积：

       W(f) = S(f) * conj(R(f)) / (|R(f)|^2 + eps)

   其中：

       S(f)：井旁地震道频谱；
       R(f)：井反射系数频谱；
       W(f)：估计子波频谱。

6. 估计后处理包括：

       fftshift 居中；
       按峰值中心裁剪；
       去均值；
       最大绝对值归一化；
       极性校正。

7. 当前估计子波长度：

       WAVELET_LEN = 41

8. 窄频子波由估计宽频子波经过 3-6-25-35 Hz 零相位滤波得到。

9. 注意：当前主样本生成流程中，窄频输入不是通过窄频子波直接褶积得到，而是由宽频合成记录低通得到。


================================================================================
五、当前宽频子波族
================================================================================

1. 当前宽频子波族主要由 B-spline 子波构成。

2. B-spline 子波构造流程：

       设定目标频带；
       构造频率-振幅控制点；
       三次 B-spline 插值；
       将振幅限制到 0-1；
       irfft 变换到时间域；
       fftshift 居中；
       按估计子波长度裁剪；
       去均值并归一化。

3. 当前配置中的 B-spline 子波频带：

       B-spline 子波 1：3-6-55-70 Hz
       B-spline 子波 2：3-6-65-80 Hz
       B-spline 子波 3：3-6-75-90 Hz

4. 当前 build_wavelet_bank 的实际逻辑：

       先计算四口井估计子波的平均值 reference；
       reference 当前只用于确定 B-spline 子波长度；
       bank 初始为空；
       只循环加入 3 个 B-spline 子波。

5. 因此当前实际进入训练的 wavelet_bank 为：

       bspline_55_70hz
       bspline_65_80hz
       bspline_75_90hz

6. 当前 estimated_wavelet 没有加入 wavelet_bank。


================================================================================
六、合成反射系数剖面生成
================================================================================

1. 四口井构造所有 2 井、3 井、4 井组合：

       2 井组合：6 组
       3 井组合：4 组
       4 井组合：1 组
       总计：11 组

2. 每组井组合与 3 个 B-spline 子波、2 个噪声级别组合。

3. 理论合成剖面数量：

       11 × 3 × 2 = 66 个剖面

4. 当前不再把井放在剖面最外侧，而是根据井的实际 crossline 投影到统一剖面上。

5. 井位投影公式：

       well_position = well_crossline - CROSSLINE_MIN

6. CROSSLINE_MIN = 300，剖面宽度 = 951。

7. 多井插值方式：

       按井的 crossline 从小到大排序；
       每个时间采样点单独进行横向插值；
       使用 np.interp 线性插值；
       井外侧使用边界井值外推。

8. 当前 2 井、3 井、4 井全部使用线性插值。

9. 当前没有使用 kriging，也没有使用序贯高斯扰动。

10. 该方式更平滑、更稳定，但横向随机地质变化减少。


================================================================================
七、构造扰动设计
================================================================================

1. 构造扰动函数：

       add_structural_perturbation

2. 构造扰动通过时间权重控制，主要作用于中下部。

3. 配置参数：

       STRUCTURE_START_SAMPLE = 120
       STRUCTURE_FULL_SAMPLE  = 240

4. 时间权重含义：

       0-120 采样点：基本无构造扰动；
       120-240 采样点：构造扰动逐渐增强；
       240 采样点以后：构造扰动完全生效。

5. 当前叠加的构造类型：

       线性倾斜；
       二次弯曲；
       1-3 组褶皱；
       1-2 个局部高斯隆起；
       横向随机平滑扰动；
       倾斜断层。

6. 主要构造参数：

       线性斜率：-0.025 到 0.025；
       曲率：-12 到 12；
       褶皱振幅：2 到 10 采样点；
       褶皱周期：260 到 750 道；
       局部隆起振幅：-12 到 12；
       横向扰动标准差：1.5；
       横向扰动 Gaussian 平滑 sigma = 10。

7. 断层设置：

       出现概率：45%；
       断层起始时间：STRUCTURE_FULL_SAMPLE 之后；
       断层横向位置：剖面 20%-80%；
       dip：-0.45 到 0.45；
       throw：3-10 采样点，正负随机；
       断层位移随时间逐渐增强。

8. 断层线定义：

       fault_x = x0 + dip * (t - t0)

9. 因此当前断层不是垂直断层，而是具有倾角的断层。

10. 构造位移采用线性插值：

       np.interp(sample_pos, t_axis, section[:, ix])

11. 当前不再使用最近邻位移插值。

12. 位移后沿横向做均值平滑：

       uniform_filter1d(size=5, axis=1)

13. 该操作用于降低道间阶梯状伪影和横向毛刺。


================================================================================
八、宽频合成记录与窄频输入生成
================================================================================

1. 宽频合成记录生成公式：

       clean_wide = reflectivity_2d * wide_wavelet

2. 代码中对应：

       clean_wide = convolve_reflectivity(base_refl, wavelet_item["wavelet"])

3. 当前 wide_wavelet 来自 B-spline wavelet_bank。

4. 窄频输入不是由窄频子波直接褶积生成，而是由 clean_wide 低通得到：

       clean_narrow = lowpass(clean_wide, 3-6-25-35 Hz)

5. 这种方式保证物理闭合关系：

       clean_wide = clean_narrow + residual_target

6. 该设计避免“窄频子波褶积输入”和“宽频子波褶积标签”由两个独立子波生成所导致的闭合关系不一致。


================================================================================
九、Q 滤波与低频去除
================================================================================

1. 当前配置中：

       USE_Q_FILTER = False

2. 因此主流程默认不启用 Q 滤波。

3. 代码中保留了 Q 滤波分支，但只有 USE_Q_FILTER=True 时才执行。

4. 当前配置中：

       LOWCUT_FREQ = 0

5. 因此低频去除模块实际关闭。


================================================================================
十、F3 振幅包络调制
================================================================================

1. 当前从 F3 中间 inline 提取局部振幅包络。

2. 包络提取流程：

       读取 F3 数据；
       取中间 inline；
       低通到 3-6-25-35 Hz；
       计算局部 RMS 包络；
       将包络归一化到均值为 1。

3. 包络平滑参数：

       ENVELOPE_SMOOTH_T = 30
       ENVELOPE_SMOOTH_X = 100

4. 包络应用方式：

       从 F3 包络中随机裁剪一块；
       同时调制 clean_wide 和 clean_narrow。

5. 作用：

       让合成剖面局部振幅强弱更接近 F3 实际数据；
       保持宽频与窄频之间的相对振幅关系。


================================================================================
十一、归一化方式
================================================================================

1. 当前训练归一化尺度来自 clean_wide 的 99 分位数：

       shared_scale = percentile(abs(clean_wide), 99)

2. 归一化公式：

       clean_input_norm = clip(clean_narrow / shared_scale, -1, 1)
       wide_norm        = clip(clean_wide   / shared_scale, -1, 1)

3. 标签为归一化空间中的残差：

       label_norm = clip(wide_norm - clean_input_norm, -1, 1)

4. 当前 train_inputs / val_inputs 保存低通输入。

5. 当前 train_labels / val_labels 保存 residual label。

6. 注意：当前训练尺度来自 clean_wide p99，而推理尺度来自 narrow_raw p99。

7. 因此当前训练与推理归一化尺度仍不完全一致。

8. 这是当前代码版本中仍然存在的关键风险点。


================================================================================
十二、噪声设置
================================================================================

1. 当前噪声级别：

       NOISE_LEVELS = [0.01, 0.03]

2. 噪声添加位置：

       归一化之后；
       只加到 input_norm；
       不加到 label_norm。

3. 当前训练样本关系：

       输入 = 干净低通输入 + 随机噪声；
       标签 = 干净高频残差。

4. 噪声用于提高网络对轻微输入扰动的稳定性。

================================================================================
十四、网络结构
================================================================================

1. 主体网络：

       UNetCBAM

2. 输入输出：

       输入：1 × 256 × 256 低通地震 patch；
       输出：1 × 256 × 256 高频残差 patch。

3. UNet 结构：

       4 层下采样；
       4 层上采样；
       skip connection；
       最终 1×1 卷积输出 residual。

4. CBAM 注意力：

       Channel Attention；
       Spatial Attention。

5. 当前训练脚本外包一层 ZeroMeanResidualModel。

6. ZeroMeanResidualModel 核心操作：

       out = UNetCBAM(x)
       out = out - mean(out)

7. 均值计算维度：

       dim = (-2, -1)

8. 作用：

       强制每个 patch 输出残差零均值；
       抑制 DC 偏置；
       防止预测残差携带低频基线漂移。


================================================================================
十五、训练数据读取逻辑
================================================================================

1. Dataset 类：

       ResidualPatchDataset

2. 读取文件：

       train_inputs.npy / val_inputs.npy
       train_labels.npy / val_labels.npy

3. 单样本定义：

       x = low-pass input
       r = residual label
       y = x + r

4. Dataset 返回：

       x：低通输入；
       y：宽频目标；
       r：残差目标。

5. 因此训练时同时约束：

       residual_pred 与 residual_target；
       x + residual_pred 与 x + residual_target。


================================================================================
十六、数据增强
================================================================================

1. 当前训练增强包括：

       左右翻转：axis=1，概率 50%；
       上下翻转：axis=0，概率 50%。

2. 左右翻转用于模拟横向方向反转。

3. 上下翻转会改变时间方向，使浅层和深层顺序倒置。

4. 从地震物理意义上看，上下翻转不合理。

5. 当前代码版本仍保留上下翻转，这是待修改点。


================================================================================
十七、损失函数设计
================================================================================

1. 当前损失函数：

       ResidualBandConstrainedLoss

2. 总损失：

       Loss = 1.0 * loss_wide
            + 0.2 * loss_res_l1
            + mean_weight * loss_mean
            + 1.0 * loss_rb
            + 0.5 * loss_er

3. 默认：

       mean_weight = 0.1


--------------------------------------------------------------------------------
17.1 宽频重建损失
--------------------------------------------------------------------------------

1. 定义：

       loss_wide = L1(wide_pred, wide_target)

2. 其中：

       wide_pred   = x + residual_pred
       wide_target = x + residual_target

3. 作用：

       约束最终宽频预测结果；
       保证残差加回后的整体波形合理。


--------------------------------------------------------------------------------
17.2 残差 L1 损失
--------------------------------------------------------------------------------

1. 定义：

       loss_res_l1 = L1(residual_pred, residual_target)

2. 作用：

       直接约束网络输出的高频残差；
       避免只通过宽频重建间接约束残差。


--------------------------------------------------------------------------------
17.3 残差均值损失
--------------------------------------------------------------------------------

1. 定义：

       loss_mean = abs(mean(residual_pred))

2. 作用：

       压制 residual 的 DC 分量；
       防止预测结果整体偏正或偏负。


--------------------------------------------------------------------------------
17.4 残差频带损失
--------------------------------------------------------------------------------

1. 函数：

       residual_band_loss

2. 约束频带：

       25-75 Hz

3. 定义：

       loss_rb = loss_amp + 0.3 * loss_phase

4. 振幅损失：

       loss_amp = mean(| |P_band| - |L_band| |)

5. 相位损失：

       loss_phase = mean(1 - cos(angle(P_band) - angle(L_band)))

6. 其中：

       P_band：预测残差在 25-75 Hz 的频谱；
       L_band：标签残差在 25-75 Hz 的频谱。

7. 作用：

       直接在 residual 上约束补频带；
       避免 full-band wide prediction 中低频能量主导梯度。


--------------------------------------------------------------------------------
17.5 高频能量比损失
--------------------------------------------------------------------------------

1. 函数：

       residual_energy_ratio_loss

2. 约束频带：

       35-75 Hz

3. 能量比定义：

       ratio = mean(|FFT(residual)| in 35-75 Hz) / mean(|FFT(residual)| all)

4. 损失形式：

       loss_er = ReLU(ratio_label - ratio_pred)

5. 特点：

       只惩罚预测高频能量不足；
       不惩罚高频能量超过标签。

6. 作用：

       鼓励网络补出足够的 35-75 Hz 高频残差；
       缓解高频补偿偏保守。


================================================================================
十八、当前未包含的损失项
================================================================================

1. 当前代码尚未包含：

4. 当前 loss 尚未单独增强 55-80 Hz 高频补偿。

================================================================================
二十、F3 推理流程
================================================================================

1. 对 F3 每条 inline：

       target = F3 原始宽频数据
       narrow_raw = zero_phase_filter(target, 3-6-25-35 Hz)

2. 推理归一化：

       narrow_scale = percentile(abs(narrow_raw), 99)
       narrow_norm  = clip(narrow_raw / narrow_scale, -1, 1)

3. 滑动窗口预测：

       patch_size = 256
       stride = 64

4. 每个 patch 输入网络，输出 residual_norm。

5. 多 patch 融合使用二维 blend window。

6. blend window 特点：

       中心权重大；
       边缘权重低；
       edge_weight = 0.15。

7. 融合后得到完整 inline 的 residual_norm。

8. 后处理残差带通：

       RESIDUAL_POST_BAND = 25-35-55-75 Hz

9. 当前推理反归一化逻辑：

       wide_norm = narrow_norm + residual_norm
       wide_pred = wide_norm * narrow_scale * R_MEDIAN
       residual_pred = wide_pred - narrow_raw

10. 注意：当前推理阶段仍使用 R_MEDIAN。

11. 之后对 residual_pred 做目标频带增益校正。

12. 目标频带增益校正参数：

       band_low = 35 Hz
       band_high = 75 Hz
       target_ratio = 0.35
       max_gain = 2.0

13. 增益校正逻辑：

       计算 residual 的 35-75 Hz 能量占比；
       如果低于 target_ratio，则增强该频带；
       最大增益不超过 max_gain。

14. direct 重组结果：

       wide_direct = narrow_raw + residual_pred

15. highpass residual 重组结果：

       residual_hp = highpass(residual_pred, 30-35 Hz transition)
       wide_highpass = narrow_raw + residual_hp

16. highpass 设置：

       30 Hz 以下置零；
       30-35 Hz 线性过渡；
       35 Hz 以上保留。

       Spectrum L1 distance

3. 评价对象：

       narrow_vs_reference：低通输入 vs F3 原始参考；
       prediction_vs_reference：预测结果 vs F3 原始参考；
       direct_vs_reference：direct 重组结果 vs F3 原始参考；
       highpass_vs_reference：高通残差重组结果 vs F3 原始参考。

4. 频谱计算方式：

       沿时间轴做 rFFT；
       对所有 trace 的振幅谱求平均；
       对平均谱归一化；
       计算频带能量占比和谱 L1 距离。

================================================================================
二十四、当前实验的核心闭合关系
================================================================================

1. 样本生成阶段：

       clean_wide = reflectivity * B-spline wavelet
       clean_narrow = lowpass(clean_wide)
       residual_label = wide_norm - narrow_norm
       wide_target = narrow_norm + residual_label

2. 训练阶段：

       residual_pred = model(narrow_norm)
       wide_pred = narrow_norm + residual_pred

3. 推理阶段：

       narrow_raw = lowpass(F3_original)
       residual_pred = model(narrow_norm)
       wide_pred = narrow_raw + residual_pred

4. 物理思想：

       低频主体由真实低通数据提供；
       网络只负责补偿缺失高频残差；
       最终结果由低频主体和预测残差叠加得到。


================================================================================
二十五、当前代码版本的关键特点
================================================================================

1. 训练目标是 residual，不是直接 wide。

2. 宽频合成由 B-spline 子波褶积生成。

3. 窄频输入由宽频合成低通得到，保证宽窄闭合。

4. 反射系数剖面使用实际 crossline 投影的多井线性插值。

5. 构造扰动主要作用于中下部，浅部基本保持平行层状。

6. 断层为倾斜断层，不再是纯垂直断层。

7. 位移采用线性插值，降低阶梯伪影。

8. Q 滤波关闭。

9. 低频去除关闭。

10. F3 低通振幅包络用于调制合成剖面。

11. 网络输出 residual 后强制零均值。

12. loss 同时约束宽频重建、残差 L1、残差均值、残差 25-75 Hz 频谱、35-75 Hz 高频能量比。

13. 推理阶段保存 direct 和 highpass residual 两种重组结果。


================================================================================
二十六、当前代码仍保留的风险点
================================================================================

1. wavelet_bank 当前没有 estimated_wavelet，只有 3 个 B-spline 子波。

2. B-spline 子波没有经过井旁低频地震筛选。

3. 训练归一化使用 clean_wide 的 p99，推理归一化使用 narrow_raw 的 p99，尺度仍不完全一致。

4. 推理阶段仍使用 R_MEDIAN，可能改变低频主体尺度。

5. 训练增强仍包含上下翻转，不符合地震时间轴物理意义。

6. loss 没有单独惩罚 0-25 Hz residual 低频泄漏。

7. loss 没有单独增强 55-80 Hz 高频补偿。


================================================================================
二十七、一句话概括当前方案
================================================================================

当前实验是一个“几何约束多井合成样本 + B-spline 宽频子波族 + residual-band-constrained UNet-CBAM”的地震拓频方案。

其核心闭合关系是：

       宽频合成 → 低通得到输入 → 宽频减低通得到残差标签 → 网络预测残差 → 加回实际低通数据

当前方案已经从“直接宽频预测”转向了更合理的“低频保持 + 高频残差补偿”，但代码中仍需进一步修正归一化一致性、R_MEDIAN、estimated_wavelet、上下翻转和高频专项 loss。
