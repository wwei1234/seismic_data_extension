一、训练样本生成（09 方案）
================================================================================

1.1 数据来源
--------------------------------------------------------------------------------

反射系数：从四口井（F02-1, F03-2, F03-4, F06-1）的波阻抗数据计算。
子波：由井反射系数和井旁地震道做频率域反褶积估计得到：
    W(f) = S(f) * conj(R(f)) / (|R(f)|^2 + 0.03)
然后分别整形到窄频带和宽频带：
    窄频子波：3-6-25-35 Hz 梯形带通
    宽频子波：3-6-55-75 Hz 梯形带通
以上数据来自 01_basic_strategy 的预计算结果。


1.2 构造反射系数剖面（build_structural_reflectivity）
--------------------------------------------------------------------------------

输入：一维反射系数序列 r1d，剖面宽度 1024 道

叠加的构造扰动：
  (a) 线性倾斜：斜率 uniform(-0.12, 0.12) 采样点/道
  (b) 二次弯曲：曲率 uniform(-35, 35)
  (c) 褶皱（2-4 组正弦波）：
      - 振幅 uniform(3.0, 15.0) 采样点   ← 已从原来的 (6,35) 降低
      - 周期 uniform(140, 650) 道
      - 初相 uniform(0, 2π)
  (d) 局部挠曲（1-3 个高斯隆起）：振幅 uniform(-28, 28)，宽度 uniform(70, 240)
  (e) 断层：
      - 主断层概率 65%，断距 uniform(-28, 28)，位置在 25%-75% 宽度
      - 次级断层概率 25%，断距 uniform(-16, 16)
  (f) 横向随机抖动：高斯噪声 std=3.5，高斯平滑 σ=7 道
  (g) 纵向随机抖动：高斯噪声 std=0.75 + 正弦扰动（周期 90-220，振幅 1.2），高斯平滑 σ=6

水平位移后，用 np.interp 将一维反射系数映射到每道的采样位置。

最后做横向平滑：uniform_filter1d(section, size=5, axis=1)
→ 消除最近邻插值引入的道间毛刺，size=5 对相邻 5 道取均值。


1.3 褶积
--------------------------------------------------------------------------------

用每口井的窄频子波和宽频子波分别与二维反射系数剖面做褶积：
    clean_narrow = convolve_reflectivity(reflectivity_2d, narrow_wavelet)
    clean_wide   = convolve_reflectivity(reflectivity_2d, wide_wavelet)

褶积沿时间轴逐道进行，使用 scipy.signal.fftconvolve，mode="same"。


1.4 Q 滤波（时变衰减）
--------------------------------------------------------------------------------

Q 滤波施加在褶积后的合成道上（不是反射系数上），物理上更正确。

参数：
    Q = 60（F3 砂泥岩地层典型值，值越小衰减越强）
    strength = 0.35
    窗口 = 96 采样点（384 ms），步长 = 24（75% 重叠）

实现：逐道短时傅里叶变换（STFT），对每个时间窗的频谱乘以 exp(-strength * π * f * t / Q)，
t 为窗中心时间。窗函数为 Tukey 窗（α=0.35），重叠相加重建。

效果：深层（1.8s 附近）振幅比浅层衰减约 40-50%。


1.5 归一化（共享尺度）
--------------------------------------------------------------------------------

步骤：
    shared_scale = percentile(|clean_wide|, 99)     # wide 标签的 99 分位数
    input_norm = clip(clean_narrow / shared_scale, -1, 1)
    label_norm = clip(clean_wide   / shared_scale, -1, 1)

关键特性：
    - 窄频输入和宽频标签除以同一个常数
    - 保留了窄/宽之间的相对幅度关系
    - 窄频通常振幅更小，归一化后在 [-1,1] 内不会填满，std 约 0.38
    - 宽频标签 std 约 0.24，两者比例反映真实的窄宽频能量差
    - 记录的 min/max 为 ±shared_scale，用于后续可能的幅度还原

对比旧方案（01_basic_strategy）：旧方案对输入和标签分别做 min-max 归一化到 [-1,1]，
两者独立缩放，丢失了窄宽频幅度关系，且引入了 DC 偏置（旧方案窄频均值 +0.07）。


1.6 噪声添加
--------------------------------------------------------------------------------

噪声在归一化之后添加（旧方案在归一化之前），噪声标准差直接以归一化后的信号为单位：

    噪声档位：0.0, 0.01, 0.02, 0.05  ← 大幅降低（旧方案 0.05/0.10/0.15/0.20）

    if noise_level > 0:
        noise = N(0, noise_level)           # 标准差为 noise_level
        input_norm = clip(input_norm + noise, -1, 1)

噪声标准差 0.05 对应归一化后信号 std≈0.38 的约 13%，模拟高信噪比叠后数据。
保留 noise_level=0.0 档（无噪声），让网络见过干净输入。


1.7 低频去除（当前已关闭）
--------------------------------------------------------------------------------

config.py 中 LOWCUT_FREQ = 8.0 Hz，但命令行参数 --lowcut 可覆盖。

当前运行使用 --lowcut 0（关闭）。
原因：去掉 8Hz 高通后，合成剖面的低频背景更接近 F3 实际数据。
是否需要此步骤待后续对比 F3 频谱后决定。

如启用：对褶积后的合成道做 8Hz 四阶 Butterworth 高通滤波（零相位 filtfilt）。


1.8 切片
--------------------------------------------------------------------------------

参数：
    剖面大小：462 时间采样点 × 1024 道
    切片大小：256 × 256
    步长：64（75% 重叠）

二、训练方案（07 残差频带约束）
================================================================================

2.1 网络结构
--------------------------------------------------------------------------------

ZeroMeanResidualModel：
    UNetCBAM (base_c=32, in_channels=1, out_channels=1)
    → 输出减去自身均值：out = out - out.mean(dim=(-2,-1), keepdim=True)

CBAM = Convolutional Block Attention Module（通道注意力 + 空间注意力）
UNet 结构：4 层下采样 (maxpool) + 4 层上采样 (transpose conv)，跳跃连接。

输入/输出：单通道 256×256 浮点张量。


2.2 残差预测范式
--------------------------------------------------------------------------------

不直接预测宽频结果。网络学习残差（宽频 - 窄频），然后加回：

    residual_pred = model(narrow_input)          # 网络输出残差（经过零均值）
    wide_pred = narrow_input + residual_pred      # 重建宽频


2.3 损失函数（ResidualBandConstrainedLoss）
--------------------------------------------------------------------------------

总损失 = 1.0 × loss_wide + 0.2 × loss_res_l1 + 0.1 × loss_mean
         + 1.0 × loss_rb + 0.5 × loss_er

各项定义：

  (a) loss_wide = L1(wide_pred, wide_label)
      全频宽频预测的 L1 损失，保证整体波形相似。

  (b) loss_res_l1 = L1(residual_pred, residual_label)
      残差本身的 L1 损失，让残差预测接近真实残差。

  (c) loss_mean = |mean(residual_pred)|   （每个 patch 的均值取绝对值后平均）
      强制残差均值为 0，防止 DC 偏置。

  (d) loss_rb = residual_band_loss(residual_pred, residual_label)
      只对残差的 25-75 Hz 频带做幅度谱和相位谱约束：
          P = FFT(residual_pred),  L = FFT(residual_label)
          band_mask = (freqs >= 25) & (freqs <= 75)
          loss_amp = mean(| |P_band| - |L_band| |)
          loss_phase = mean(1 - cos(angle(P_band) - angle(L_band)))
          loss_rb = loss_amp + 0.3 × loss_phase
      关键：在残差上做频域约束，残差天然只有补频带能量，不存在低频
      主导梯度的问题。相比在 wide_pred 上做全频加权（06 方案），更直接有效。

  (e) loss_er = residual_energy_ratio_loss(residual_pred, residual_label)
      非对称能量比损失，只惩罚高频能量不足：
          ratio = energy(35-75 Hz) / energy(total)
          loss = ReLU(ratio_label - ratio_pred).mean()
      当预测残差的高频占比低于标签时产生梯度，高于标签时不惩罚。


2.4 训练配置
--------------------------------------------------------------------------------

优化器：Adam，初始学习率 1e-3
学习率调度：ReduceLROnPlateau，监控 val total loss，patience=10，factor=0.5
批大小：4
最大轮数：300
早停 patience：300（实际不早停）
数据增强：随机左右翻转（50%）、随机上下翻转（50%）


2.5 训练数据
--------------------------------------------------------------------------------

当前 07 实验使用的训练数据来自 01_basic_strategy/data/（旧方案生成）。

3.1 预处理
--------------------------------------------------------------------------------

    target = read_segy(F3原始数据)                         # 651 × 462 × 951
    narrow_raw = zero_phase_filter_section(target, DT,     # 3-6-25-35 Hz 低通
                                           NARROW_BAND)
    narrow_norm = minmax_with_stats(narrow_raw)            # min-max → [-1, 1]
    记录 narrow_min, narrow_max 用于反归一化


3.2 滑动窗口推理
--------------------------------------------------------------------------------

    窗口大小：256 × 256
    步长：64（75% 重叠）
    权重窗：二维线性渐变（中心权重 1.0，边缘权重 0.15）

    对每个窗口：
        patch = narrow_norm[t0:t0+256, x0:x0+256]
        residual = model(patch)                           # 网络预测残差
        output[t0:t0+256, x0:x0+256] += residual × window
        weight[t0:t0+256, x0:x0+256] += window

    融合：output / weight

    后处理：
        residual_norm = bandpass(output, 25-35-55-75)     # 残差带通滤波兜底
        wide_norm = narrow_norm + residual_norm
        wide_pred = inverse_minmax(wide_norm, mn, mx)     # 反归一化到原始幅度
        residual_pred = wide_pred - narrow_raw

    增益校正：
        residual_pred = targeted_gain_correction(
            residual_pred, target_ratio=0.35, max_gain=2.0
        )
        → 只对 35-75 Hz 做增益，不动其他频段
        → 如果当前高频占比 < 0.35，放大该频段（最多 2 倍）
        → 避免过度放大噪声


3.2 评价指标
--------------------------------------------------------------------------------

    Corr（皮尔逊相关系数）
    MAE / RMSE
    35-80 Hz 高频能量占比
    频谱 L1 距离（vs F3 参考）

4.1 训练与推理归一化不一致（重要）
--------------------------------------------------------------------------------

训练（09 方案）：
    input_norm = clip(narrow / shared_scale, -1, 1)     ← 除以 wide 的 99 分位数

推理（07 方案）：
    narrow_norm = 2*(narrow - min)/(max - min) - 1      ← min-max 仿射变换

两种变换不同，导致网络在推理时接收的输入分布与训练时不同。
如果用 09 数据训练，必须将推理脚本的归一化改为与训练一致的 shared-scale 方式：

    ref_scale = percentile(|F3_original|, 99)            # 用 F3 原始数据计算
    narrow_norm = clip(narrow_raw / ref_scale, -1, 1)
    # 反归一化
    wide_pred = wide_norm × ref_scale

当前 07 实验使用 01 旧数据（独立 min-max 归一化），训练与推理一致，不受此影响。
切换到 09 数据训练前必须修复。


4.2 低频去除开关
--------------------------------------------------------------------------------

当前 09 生成默认 LOWCUT_FREQ=8.0，但上次运行用了 --lowcut 0 关闭。
保留 8 Hz 高通时：宽频标签 35-80Hz 占比 = 0.479
去掉高通时：      宽频标签 35-80Hz 占比 = 0.413
F3 原始参考：                    35-80Hz 占比 = 0.591

需对比实际 F3 数据的低频特征后决定是否保留高通。


4.3 窄频子波与 F3 低通数据频谱不匹配
--------------------------------------------------------------------------------

窄频子波（整形到 3-6-25-35 Hz）频谱特征：
    峰值频率：~17 Hz
    0-35 Hz 能量占比：76%

实际井旁地震道：
    峰值频率：~36 Hz
    0-35 Hz 能量占比：43%

训练时网络见到的窄频输入比推理时 F3 低通数据更"窄"（更偏低频），
输入分布存在偏移。可能需要调整窄频子波的整形频带。
