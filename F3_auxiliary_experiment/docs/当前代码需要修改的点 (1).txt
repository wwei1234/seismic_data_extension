当前代码需要修改的点
====================

实验名称建议：bspline_v3 / 16_fidelity_constrained_bspline_residual
整理目的：记录当前代码中仍未完成、需要下一轮修改的关键点，便于交给 Codex 修改。


一、最高优先级：训练与推理归一化不一致
--------------------------------------

1. 当前问题

当前 02_generate_synthetic_dataset.py 中训练样本归一化尺度仍来自 clean_wide 的 99 分位数：

    shared_scale = float(np.percentile(np.abs(clean_wide), 99))

但 02_predict_f3.py 推理时只能使用实际低通输入 narrow_raw 的 99 分位数：

    narrow_scale = float(np.percentile(np.abs(narrow_raw), 99))

这会导致训练与推理尺度不一致。

2. 修改目标

训练和推理都统一使用窄频输入的 p99 尺度。

3. 修改位置

文件：02_generate_synthetic_dataset.py

将：

    shared_scale = float(np.percentile(np.abs(clean_wide), 99))

改为：

    shared_scale = float(np.percentile(np.abs(clean_narrow), 99))
    shared_scale = max(shared_scale, 1e-8)

并保持：

    clean_input_norm = np.clip(clean_narrow / shared_scale, -1.0, 1.0).astype(np.float32)
    wide_norm = np.clip(clean_wide / shared_scale, -1.0, 1.0).astype(np.float32)
    label_norm = np.clip(wide_norm - clean_input_norm, -1.0, 1.0).astype(np.float32)

4. 技术目的

保证训练阶段和推理阶段的尺度定义一致，避免网络在训练中学习到 wide_p99 尺度，而推理时输入 narrow_p99 尺度导致残差幅值偏差。


二、最高优先级：去掉推理阶段 R_MEDIAN
-----------------------------------

1. 当前问题

common.py 中仍保留：

    R_MEDIAN = _meta.get("r_median", 1.8)

02_predict_f3.py 中仍导入并使用 R_MEDIAN：

    wide_pred = wide_norm * narrow_scale * R_MEDIAN
    residual_pred = wide_pred - narrow_raw

这会改变最终结果的低频主体尺度，不利于保真。

2. 修改目标

推理阶段不再使用任何 wide/narrow 全局比例因子。
网络只预测 residual，低频主体 narrow_raw 必须原样保留。

3. 修改位置

文件：02_predict_f3.py

删除 common 导入中的 R_MEDIAN。

将：

    wide_norm = narrow_norm + residual_norm
    wide_pred = wide_norm * narrow_scale * R_MEDIAN
    residual_pred = wide_pred - narrow_raw

改为：

    residual_pred = residual_norm * narrow_scale

后续保持：

    residual_pred = targeted_gain_correction(...)
    wide_direct = narrow_raw + residual_pred
    residual_hp = highpass_section(residual_pred, DT, args.hp_cut1, args.hp_cut2)
    wide_highpass = narrow_raw + residual_hp

4. 技术目的

保证最终预测结果满足：

    wide_pred = narrow_raw + residual_pred

其中 narrow_raw 不被任何全局尺度因子修改。


三、高优先级：删除上下翻转数据增强
------------------------------

1. 当前问题

01_train.py 中 ResidualPatchDataset.__getitem__ 当前包含上下翻转：

    if np.random.rand() < 0.5:
        x = np.flip(x, axis=0)
        r = np.flip(r, axis=0)

axis=0 是时间方向，上下翻转会破坏浅层到深层的时间顺序。

2. 修改目标

只保留横向左右翻转，不保留时间方向上下翻转。

3. 修改位置

文件：01_train.py

将增强逻辑改为：

    if self.augment:
        if np.random.rand() < 0.5:
            x = np.flip(x, axis=1)
            r = np.flip(r, axis=1)

4. 技术目的

保持地震时间轴物理顺序，避免网络学习到不合理的倒置地层结构。

2. 修改目标

3. 修改位置

五、中高优先级：增加 0–25 Hz residual 低频泄漏惩罚
------------------------------------------------

1. 当前问题

当前网络预测的是 residual，理论上 residual 不应包含明显 0–25 Hz 低频成分。
但当前 loss 中没有明确惩罚 residual 的低频泄漏。

当前 loss 只有：

    loss_wide
    loss_res_l1
    loss_mean
    loss_rb
    loss_er

2. 修改目标

新增 residual_lowfreq_leak_loss，惩罚预测残差在 0–25 Hz 的振幅能量。

3. 修改位置一

文件：common.py

新增函数：

    def residual_lowfreq_leak_loss(pred_residual, dt=DT, low=0.0, high=25.0):
        """
        Penalize low-frequency leakage in predicted residual.
        The residual should not contain strong 0-25 Hz energy because the low-frequency
        component is already provided by the low-pass input.
        """
        nt = pred_residual.shape[-2]
        P = torch.fft.rfft(pred_residual, dim=-2)
        freqs = torch.fft.rfftfreq(nt, d=dt, device=pred_residual.device)
        mask = (freqs >= low) & (freqs < high)
        return P[:, :, mask, :].abs().mean()

4. 修改位置二

文件：01_train.py

在 common 导入中增加：

    residual_lowfreq_leak_loss

在 ResidualBandConstrainedLoss.forward 中增加：

    loss_low = residual_lowfreq_leak_loss(residual_pred)

总损失加入：

    + 0.5 * loss_low

loss_dict 中增加：

    "low": float(loss_low.detach().cpu())

keys 中增加：

    "low"

5. 技术目的

限制网络把低频成分混入 residual，使最终低频主体主要由 narrow_raw 提供，提高低频保真性。


六、中高优先级：增加 55–80 Hz 高频专项约束
-----------------------------------------

1. 当前问题

当前 residual_band_loss 约束 25–75 Hz，residual_energy_ratio_loss 约束 35–75 Hz。
但实际问题是 55 Hz 以上补偿偏弱，当前 loss 没有单独加强 55–80 Hz。

2. 修改目标

新增 residual_highband_loss，单独约束 55–80 Hz 的 residual 振幅谱。

3. 修改位置一

文件：common.py

新增函数：

    def residual_highband_loss(pred_residual, label_residual, dt=DT, low=55.0, high=80.0):
        """
        Extra amplitude constraint for the 55-80 Hz residual band.
        This band is currently under-compensated, so it is constrained separately.
        """
        nt = pred_residual.shape[-2]
        P = torch.fft.rfft(pred_residual, dim=-2)
        L = torch.fft.rfft(label_residual, dim=-2)
        freqs = torch.fft.rfftfreq(nt, d=dt, device=pred_residual.device)

        mask = (freqs >= low) & (freqs <= high)
        return torch.abs(P[:, :, mask, :].abs() - L[:, :, mask, :].abs()).mean()

4. 修改位置二

文件：01_train.py

在 common 导入中增加：

    residual_highband_loss

在 ResidualBandConstrainedLoss.forward 中增加：

    loss_high = residual_highband_loss(residual_pred, residual_target)

总损失加入：

    + 1.0 * loss_high

loss_dict 中增加：

    "high": float(loss_high.detach().cpu())

keys 中增加：

    "high"

plot_history 中建议增加 high 曲线。

5. 技术目的

增强 55–80 Hz 频段的学习权重，缓解预测残差高频补偿偏弱的问题。

十二、一句话总结
--------------

这次修改的核心不是换网络，而是修正实验闭合逻辑：

    训练/推理统一 narrow_p99 尺度；
    推理去掉 R_MEDIAN；
    低频主体严格保持 narrow_raw；
    网络只预测 residual；
    residual 不能泄漏低频；
    55–80 Hz 高频单独加强；
    样本子波族加入 estimated_wavelet，避免完全依赖人工 B-spline 子波。
