F3 地震数据拓频项目技术改进路线总结
====================================

整理日期：2026-06-23

说明：
1. 本文根据项目 docs 文档、shared_code、14～17 号实验代码、样本元数据、
   训练日志和井位 inline/crossline 评价报告综合整理。
2. 文档中的历史设想与后续实际代码不一致时，以当前代码、生成元数据和
   已保存的实验结果为准。
3. 本项目的核心目标不是单纯增加高频能量，而是在尽量保持原始低频主体、
   同相轴位置和相位关系的前提下，实现可解释、可验证的数据拓频。


一、数据读取与井震匹配改进
==========================

1. 早期问题：按固定 trace 数切分 SEG-Y

早期读取方法默认每个 inline 具有相同 trace 数，并按固定长度连续切分
Seismic_data.sgy。实际 F3 工区不同 inline 的 trace 数并不完全一致：

    inline 数量：651
    crossline 全局范围：300～1250，共 951 个位置
    单个 inline 实际 trace 数：约 570～951

因此，固定分块可能把前一个 inline 的尾部和后一个 inline 的头部拼成同一
剖面。这不仅会破坏剖面几何，还会造成井位置、井旁地震道和测井反射系数
之间的错误匹配，进而影响估计子波。

2. 当前解决方案：按 SEG-Y 几何头重建数据体

shared_code/segy_reader.py 使用 inline/crossline 头字段建立几何索引，并重建：

    seismic_cube[inline_index, time_index, crossline_index]

读取时按真实 inline、crossline 坐标定位，不再把固定 trace 数作为主要
几何依据。缺失网格位置进行受控填充，固定分块只保留为兼容性后备方案。

3. 井震重新匹配

在几何读取修正后，重新执行井位匹配、井旁地震道提取和子波估计。当前四口
井的定位为：

    F02-1：inline 362，crossline 336
    F03-2：inline 722，crossline 848
    F03-4：inline 442，crossline 1007
    F06-1：inline 244，crossline 387

重复使用的井数据和子波数据已经归档到 shared_data，包括：

    well_reflectivities.npy
    well_traces.npy
    well_trace_matches.npy
    well_wavelet_tie_scores.npy
    well_estimated_wavelets.npy
    well_wide_wavelets.npy
    well_narrow_wavelets.npy
    estimated_wide_wavelet.npy
    estimated_narrow_wavelet.npy
    well_wavelet_pairs.npy

4. 本阶段的意义

几何修正是后续所有改进的前提。若井旁地震道提取位置错误，即使网络、损失
函数和样本数量继续优化，估计子波与实际工区的相位和频谱关系仍不可信。
因此，从 14 号以后的有效实验，应以几何头读取和重新匹配后的共享数据为准。


二、合成样本真实性改进
======================

1. 从简单拼接向真实横向几何过渡

早期样本主要根据少量井反射系数进行横向扩展，结构扰动覆盖范围较大，
容易生成与实际 F3 同相轴连续性不一致的剖面。

13～15 号实验尝试普通克里金和 SGS 随机模拟。该方案可以引入空间变化，
但三井、四井组合中逐时间采样点独立的随机扰动会造成细小错断、横向碎裂
和不自然的高频纹理。样本虽然更“复杂”，但复杂性未必符合真实沉积结构。

2. 16、17 号采用实际 crossline 坐标线性插值

当前 16、17 号样本生成不再对二井、三井、四井组合使用逐采样点 SGS，
而是：

    - 将井投影到实际 crossline 坐标；
    - 按井的实际横向顺序进行分段线性插值；
    - 两端区域使用边界井控制的外推；
    - 保留二井、三井、四井共 11 种井组合。

这种方法牺牲了一部分随机变化，但显著提高了同相轴连续性和井位约束的
可解释性，适合作为当前基准样本生成方法。

3. 时间方向位移改进

旧实现通过 np.rint 将时间位移取整，再按最近邻采样搬移反射系数。其结果
会在相邻 trace 间产生一采样点跳变，表现为标签中的细小错断。

当前方法使用 np.interp 进行线性时间重采样，使倾斜同相轴和断层附近的
变化连续。后续若仍存在明显锯齿，可对比三次插值，但应注意避免产生过冲。

4. 结构扰动范围改进

当前结构扰动不再覆盖整个时间轴，而是分层控制：

    STRUCTURE_START_SAMPLE = 120
    STRUCTURE_FULL_SAMPLE  = 240

浅层保持相对稳定，中深层逐步增强构造扰动，避免浅层出现不符合实际的
强烈弯曲和随机错断。断层位置使用随时间变化的倾斜表达，而不是简单垂直
切断：

    fault_x = x0 + dip * (t - t0)

5. 横向平滑

16、17 号实际样本在横向使用 size=5 的均匀平滑：

    uniform_filter1d(..., size=5, axis=1)

该处理用于抑制井间插值和构造扰动形成的细碎横向跳变。15 号阶段主要使用
size=3，因此 16 号是对样本连续性的进一步加强。

6. 实际 F3 包络调制

合成剖面使用实际 F3 低通数据的平滑 RMS 包络进行振幅调制，典型平滑尺度：

    时间方向：30 samples
    横向方向：100 traces

这样可以使合成数据的时变能量分布更接近实际工区，避免整张合成剖面振幅
统计过于均匀。

7. 噪声、Q 和切片策略

当前 16、17 号实际设置为：

    噪声水平：[0.01, 0.03]
    噪声添加位置：只添加到网络输入
    标签：保持无噪声
    Q 滤波：关闭，USE_Q_FILTER=False
    低切：关闭，LOWCUT_FREQ=0
    patch 大小：256 × 256
    patch 步长：128
    边缘策略：覆盖最后一个窗口
    数据增强：只做左右翻转，不做上下翻转

上下翻转被去除，是因为时间轴具有明确的地质方向，垂向翻转会制造不合理
的时序关系。步长由 64 调整为 128，减少高度重叠样本带来的重复性。

8. 当前样本规模

    11 种井组合 × 3 个宽频子波 × 2 个噪声水平 = 66 个合成剖面
    总 patch 数：1386
    训练 patch：1109
    验证 patch：277


三、子波与频带设计改进
======================

1. 估计子波阶段

项目早期使用测井反射系数 R(f) 和井旁地震道 S(f) 进行频域稳健反褶积：

    W(f) = S(f) * conj(R(f)) / (|R(f)|^2 + epsilon)

随后分别形成窄频、宽频子波，用于卷积生成样本。几何读取错误被发现后，
原估计子波的井震位置对应关系受到质疑，因此重新匹配井位是必要步骤。

2. 窄频与宽频闭合关系

早期分别使用窄频子波和宽频子波卷积，可能造成两类数据除频带外还存在
相位和波形差异。当前改为：

    clean_wide   = reflectivity * wide_wavelet
    clean_narrow = lowpass(clean_wide)
    residual     = clean_wide - clean_narrow

即窄频数据必须由同一个宽频剖面低通得到。这样能够保证：

    clean_wide = clean_narrow + residual

该闭合关系对残差监督非常重要，也便于判断网络补充的是否确实是缺失频带。

3. B-spline 宽频子波库

15 号开始使用三个 B-spline 宽频子波，主要频带设置为：

    (3, 6, 55, 70) Hz
    (3, 6, 65, 80) Hz
    (3, 6, 75, 90) Hz

16、17 号继续沿用这三个子波。当前实际代码中，估计平均子波主要用于长度
等基础设置，并未作为第四个宽频子波加入训练库。

4. 已发现的问题

“子波频带宽”不等于“合成剖面一定具有宽而均衡的有效频带”。最终剖面频谱
还受到以下因素共同控制：

    - 反射系数自身的频谱；
    - 子波各频段的实际能量分布；
    - 反射系数横向和时间平滑；
    - F3 包络调制；
    - 归一化方式；
    - 绘图色标；
    - 标签中的相位相消。

因此，判断样本是否真正拓宽不能只看子波设计参数，必须同时检查子波频谱、
合成宽频剖面频谱、低通剖面频谱和残差频谱。

5. 下一步子波设计建议

当前 B-spline 子波提高了高频覆盖，但与实际 F3 的相位和井旁统计仍可能
存在域差异。后续应：

    - 将重新估计的井震子波重新纳入候选库；
    - 按井旁实际数据的振幅谱、相位谱和主频筛选候选子波；
    - 对每个候选子波低通后与井旁低通地震进行波形匹配；
    - 控制 55～80 Hz 能量，但避免只追求高频幅值；
    - 对比零相位、估计相位和轻微相位扰动三类样本。


四、标签与归一化改进
====================

1. 从直接宽频标签转向高频残差

项目早期尝试输入窄频、直接预测宽频。由于低频主体已经存在于输入中，让
网络重建完整宽频数据会增加任务难度，并可能破坏原始低频波形。

因此主线改为：

    residual_label = clean_wide - clean_narrow
    wide_prediction = lowpass_input + predicted_residual

16 号继续使用无噪声高频残差作为标签，噪声只存在于输入中。

2. 残差低频偏置问题

残差模型早期输出可能含有直流分量和低频漂移。项目先后尝试：

    - 在损失前对输出带通；
    - 在推理阶段对残差高通；
    - 模型输出减去时间/空间均值；
    - 增加残差均值约束；
    - 增加目标频带的振幅、相位和能量约束。

其中，训练前直接强制带通虽然能减少偏置，但会遮蔽部分梯度并使高频输出
趋于保守。16 号采用 ZeroMeanResidualModel 和复合残差损失，并在推理时
同时保存“直接残差重组”和“高通残差重组”两个结果进行对比。

3. 归一化标准的演化

早期窄频、宽频分别 min-max 归一化，会丢失两者之间真实的相对振幅关系。
随后改为统一尺度，但曾使用宽频数据 P99，造成训练和实际低通推理标准不一致。

16、17 号当前实际标准为：

    scale = P99(abs(clean_narrow))

同一剖面的输入、宽频标签和残差标签共用该 scale：

    clean_input_norm = clean_narrow / scale
    noisy_input_norm = noisy_narrow / scale
    wide_norm        = clean_wide / scale
    residual_norm    = wide_norm - clean_input_norm

元数据记录为：

    normalization = per_section_p99_abs_clean_narrow

该标准与实际推理时只能获得低通输入的条件一致。

4. 17 号重新验证直接宽频标签

17 号保持 16 号的样本几何、噪声、切片和归一化，只把标签改为无噪声完整
宽频数据：

    label_type = wide_band

模型直接输出宽频归一化结果，不执行零均值处理，不与输入做残差相加：

    wide_prediction = model(noisy_lowpass) * narrow_scale

该实验的目的，是单独检验“残差标签”和“直接宽频标签”对结果的影响。


五、网络、损失函数与训练改进
============================

1. 网络主体

16、17 号均以单通道 UNet-CBAM 为主体。CBAM 用于在通道和空间维度重新分配
特征权重。网络结构保持不变，使标签和损失函数的对比更清晰。

2. 16 号残差模型

16 号在 UNet-CBAM 外增加 ZeroMeanResidualModel，使输出残差去除整体均值。
训练损失包含以下主要部分：

    - 宽频重组结果的波形 L1；
    - 残差波形 L1；
    - 残差均值约束；
    - 25～75 Hz 频带振幅约束；
    - 25～75 Hz 相位约束；
    - 35～75 Hz 高频能量比例约束。

目标是同时控制空间波形、残差偏置和目标频带能量，而不是只优化像素误差。

3. 17 号直接宽频模型

17 号取消零均值输出，因为完整宽频数据本身不应被强制为零均值残差。其
复合损失为：

    波形 L1，权重 1.0
    25～80 Hz 归一化频谱振幅损失，权重 0.5
    25～80 Hz 相位损失，权重 0.2
    时间梯度损失，权重 0.2
    3～35 Hz 低频一致性损失，权重 0.5

其中低频一致性项用于限制完整宽频预测对原始低频主体的修改。

4. 训练轮数

16、17 号均按要求训练 200 轮。17 号训练结果：

    最佳轮次：197
    最佳验证总损失：0.067708
    第 200 轮验证总损失：0.069854

训练损失持续下降，但实际 F3 评价表明，合成验证损失下降并不等价于真实
剖面空间波形指标改善。因此，后续不能只依靠合成验证集选择模型。


六、推理、重组与评价体系改进
============================

1. 井位双方向评价

修正几何后，项目不再只评价单个测试剖面，而是对四口井对应的：

    inline：244、362、442、722
    crossline：336、387、848、1007

分别进行预测和评价。这样能够同时检查沿 inline 和 crossline 方向的泛化。

2. 16 号残差推理的两个输出

16 号保存两种宽频重组结果：

    A. direct_wide = lowpass + predicted_residual
    B. highpass_wide = lowpass + highpass(predicted_residual)

直接重组保留网络预测的完整残差；高通重组用于去除预测残差中的低频泄漏。

3. 评价指标

当前同时使用：

    - MAE
    - RMSE / MSE
    - PSNR
    - 相关系数
    - 35～80 Hz 高频能量比例
    - 与实际宽频参考的频谱 L1 距离
    - 剖面图与频谱图人工检查

绘制多剖面对比时应使用统一色标。统一色标只能消除视觉尺度误导，不能替代
频谱、波形和相关性评价。

4. 16 号残差实验结果

四口井 inline 综合结果：

                       MAE       RMSE      Corr      HF ratio   Spectrum L1
    低通输入        1277.429   1876.366   0.613888   0.000000   0.338166
    直接残差重组    1742.669   2440.864   0.534848   0.352215   0.211904
    高通残差重组    1595.051   2256.588   0.450571   0.483646   0.164305

四口井 crossline 综合结果：

                       MAE       RMSE      Corr      HF ratio   Spectrum L1
    低通输入        1373.837   1952.165   0.588366   0.000000   0.372290
    直接残差重组    1496.593   2093.311   0.504902   0.359062   0.233529
    高通残差重组    1492.846   2083.433   0.513115   0.357289   0.250190

结论：两种残差重组都增加了高频，并缩小了频谱距离，但空间域 MAE、RMSE
和相关性没有超过低通基线。高通残差在 inline 上得到更接近参考的频谱，
但相关性下降明显；在 crossline 上直接和高通版本差异较小。

5. 17 号直接宽频实验结果

四口井 inline 综合结果：

                    MAE       RMSE      Corr      HF ratio   Spectrum L1
    低通输入     1277.429   1876.366   0.613888   0.000000   0.338166
    直接宽频     1533.622   2209.179   0.440370   0.449588   0.156196

四口井 crossline 综合结果：

                    MAE       RMSE      Corr      HF ratio   Spectrum L1
    低通输入     1373.837   1952.165   0.588366   0.000000   0.372290
    直接宽频     1624.815   2259.885   0.422570   0.443917   0.171131

结论：17 号对频谱形状的改善比低通基线非常明显，但空间波形指标进一步下降。
网络主要学会了补充与合成标签统计相似的高频能量，却没有保证新增高频的
相位、振幅和同相轴位置与实际 F3 宽频参考一致。因此当前结果应定义为
“频谱增强”，不能直接定义为可靠的相位一致拓频。


七、14～17 号实验的技术演化
============================

1. 14 号：几何读取修正后的过渡基线

主要作用：

    - 修正 F3 SEG-Y 变长 inline 的读取问题；
    - 重新匹配井位置、井旁道和测井数据；
    - 延续克里金/残差预测主线；
    - 建立宽度 951 的统一 crossline 网格。

仍存在的问题：

    - 样本几何和随机插值仍偏理想化；
    - 噪声水平较多；
    - Q、步长、归一化等设置尚未完全统一；
    - 旧文档与当前代码参数逐渐出现差异。

2. 15 号：B-spline 宽频子波库

主要改进：

    - 使用三种 B-spline 宽频子波加强 55～80 Hz 附近覆盖；
    - 噪声改为 0.01、0.03；
    - 去除原始估计子波直接生成的剖面；
    - 训练 300 轮，并输出直接残差、高通残差两类结果；
    - 增加二井、三井、四井合成剖面及井位投影。

暴露的问题：

    - 克里金/SGS 逐时间随机扰动造成细小错断和同相轴碎裂；
    - 子波标称宽频，但合成剖面有效频带仍受反射系数和平滑影响；
    - 不同图独立色标会产生分辨率错觉；
    - 样本统计与实际 F3 仍存在域差异。

3. 16 号：真实几何约束的残差样本与 200 轮训练

主要改进：

    - 所有井组合改为基于实际 crossline 坐标的线性插值；
    - np.rint 最近邻位移改为 np.interp；
    - 浅层稳定、中深层逐步增加构造；
    - 横向平滑改为 size=5；
    - 关闭 Q 和低切；
    - 输入只添加 0.01、0.03 噪声，标签无噪声；
    - 归一化统一为低通数据绝对值 P99；
    - 去除上下翻转；
    - patch 步长改为 128；
    - 生成 66 个剖面并训练残差模型 200 轮；
    - 对四口井 inline 和 crossline 分别评价；
    - 同时比较直接残差重组与高通残差重组。

技术判断：

16 号解决了样本几何连续性和训练/推理归一化一致性的关键问题，但评价结果
说明“补出高频能量”与“补对实际高频波形”仍有明显差距。

4. 17 号：直接预测完整宽频数据

主要改进：

    - 完全复用 16 号样本生成方式；
    - 标签由高频残差改为无噪声完整宽频数据；
    - 模型取消零均值输出；
    - 损失改为宽频波形、频谱、相位、梯度和低频一致性五部分；
    - 直接反归一化输出宽频数据，不做残差相加和后置高通；
    - 完成 200 轮训练及四口井双方向评价。

技术判断：

17 号证明直接宽频监督能够显著改善频谱距离，但网络同时重建低频主体后，
更容易改变原始波形。直接完整宽频预测目前没有优于残差旁路结构，反而强化
了“频谱正确、空间位置不正确”的矛盾。


八、当前局限与下一步建议
========================

1. 当前最主要的技术矛盾

现有模型已经能够补充 35～80 Hz 高频能量，并让平均频谱接近实际宽频数据；
但新增能量的相位、振幅和同相轴位置不够准确，导致空间域误差增大、相关性
下降。当前瓶颈不是“没有高频”，而是“高频没有补到正确位置”。

2. 推荐的主结构：低频旁路 + 高频预测

下一轮优先采用：

    predicted_high = network(lowpass_input)
    wide_prediction = lowpass_input + predicted_high

标签仍可使用完整宽频数据，损失直接比较 wide_prediction 和 wide_label。
这样兼顾：

    - 保留原始低频主体；
    - 网络主要负责缺失频带；
    - 可直接对最终宽频结果施加波形和频谱约束；
    - 避免直接宽频模型无必要地重建全部低频。

3. 强化低频保护

建议至少采用一种硬约束：

    - 将最终预测的 3～25/35 Hz 直接替换为输入低频；
    - 或在频域中只允许网络输出 25 Hz 以上成分；
    - 或显著提高低频一致性损失权重。

相比单纯增加低频损失权重，频带替换或输出掩膜更能保证低频主体不被改变。

4. 提高相位和构造一致性

下一轮损失应减少对“平均频谱相似”的过度依赖，增加：

    - 局部窗口频谱和相位损失；
    - 多尺度时间梯度损失；
    - trace 间横向梯度/结构连续性损失；
    - 高能同相轴区域的加权波形损失；
    - 井位邻域的额外监督或验证权重。

频谱损失应在多个局部时间窗和空间窗内计算，避免不同位置的错误高频在全局
平均后仍得到较好分数。

5. 缩小合成域与实际 F3 的差异

建议对实际低通数据和合成低通数据系统比较：

    - 振幅分布和 P99/P95；
    - trace RMS 和包络分布；
    - 主频、带宽和频谱斜率；
    - 自相关长度；
    - 横向相干性；
    - 局部倾角和断层附近统计；
    - 噪声类型，而不仅是白噪声强度。

根据差异调整样本，而不是继续无目标增加随机扰动。

6. 重新筛选子波库

B-spline 子波应与重新匹配后的井震估计子波共同参与候选筛选。优先保留：

    - 低通后能与实际井旁低通道匹配；
    - 高频能量覆盖目标频带；
    - 相位与实际井震关系合理；
    - 卷积后不会因相消形成异常窄带的子波。

7. 模型选择标准

后续 checkpoint 选择不能只依赖合成验证损失。建议建立双重标准：

    第一层：合成验证集总损失、波形、频谱和相位指标；
    第二层：四口井 inline/crossline 的相关性、频谱距离和剖面连续性。

只有频谱改善且空间域指标不明显恶化的模型，才适合进入下一轮。

8. 建议的下一轮对照实验

保持 16 号样本不变，只比较以下三种输出结构：

    A. 16 号零均值残差模型；
    B. 宽频标签 + 低频旁路的高频分量模型；
    C. B 模型 + 最终结果低频硬替换。

三组使用相同训练/验证划分、相同 200 轮和相同井位评价。这样能够明确判断
改进来自标签、输出结构还是后处理，而不是同时改变过多变量。

9. 代码与文档维护

shared_code 和 shared_data 已作为公共资源，后续新实验目录只保留实验特有的
代码、数据、图件和日志。需要继续执行：

    - 当前代码为参数事实来源；
    - 每轮保存 synthetic_metadata.npy；
    - 每轮 README 记录标签、归一化、噪声、样本量和训练轮数；
    - 评价报告与模型权重同时归档；
    - 删除复制后未使用的旧残差函数，避免误判实际流程；
    - 新图统一色标，并同时输出频谱数据和统计表。


最终结论
========

本项目的改进路线已经从“直接用理想合成数据预测宽频”，逐步发展为：

    几何正确读取
    → 井震重新匹配
    → 宽窄频闭合样本
    → 实际井位控制的连续剖面
    → 低通 P99 统一归一化
    → 残差与直接宽频两类监督对照
    → 四口井 inline/crossline 双方向评价

当前 16、17 号实验共同表明：模型已具备明显的频谱增强能力，但尚未实现
可靠的相位一致拓频。下一阶段不应继续单纯追求更高的 35～80 Hz 能量，
而应把重点转向低频硬保护、局部相位约束、横向结构连续性和合成域匹配。
从现有证据看，“原始低频旁路 + 网络预测高频分量 + 最终宽频监督”是最值得
优先验证的下一条技术路线。
