# 21号留一井局部宽频标定实验设计

## 1. 实验目标

创建 `21_leave_one_well_calibration` 实验，模拟以下实际部署条件：

- F3 工区大部分区域只有可获得的窄频地震数据；
- 少量井附近通过高分辨率采集、VSP 或局部标定获得宽频数据；
- 目标井及其邻域没有宽频资料；
- 模型利用其他井旁局部宽频标定区和无宽频监督数据，对目标井区域进行拓频。

实验采用四折留一井评价。每一折使用三口井附近的局部宽频窗口微调模型，第四口井及其保护区完全留出。四折使用相同的模型结构、损失权重、训练轮数和模型选择规则。

本实验的目标不是复现 18 号使用全区宽频监督的上限结果，而是检验少量、空间局限的宽频标定能否迁移到未标定井区。

## 2. 四口井与四折定义

四口井的 inline/crossline 坐标按现有工程顺序配对：

| 井序号 | Inline | Crossline |
|---|---:|---:|
| Well 1 | 244 | 336 |
| Well 2 | 362 | 387 |
| Well 3 | 442 | 848 |
| Well 4 | 722 | 1007 |

四折定义：

| Fold | 局部宽频标定井 | 完全留出井 |
|---|---|---|
| fold_well1 | Well 2、Well 3、Well 4 | Well 1 |
| fold_well2 | Well 1、Well 3、Well 4 | Well 2 |
| fold_well3 | Well 1、Well 2、Well 4 | Well 3 |
| fold_well4 | Well 1、Well 2、Well 3 | Well 4 |

每折只对对应留出井的完整 inline 和完整 crossline 生成最终预测与评价。四折完成后，将四个留出井结果汇总为总体 inline 和 crossline 指标。

## 3. 数据使用边界

### 3.1 公共预训练允许使用

- F3 窄频数据及其多频带遮蔽自监督任务；
- 测井反射系数和井震匹配结果；
- 测井约束合成宽频样本及其低通输入；
- 16 号或 20 号实验中不含 F3 宽频目标的样本生成规则；
- F3 窄频数据的振幅、包络和空间结构统计。

公共预训练禁止读取任何 F3 实际宽频目标。预训练模型只训练一次，并作为四折微调的共同初始化。

### 3.2 每折局部宽频标定区

对每口参与标定的训练井，允许读取以下三维窗口中的 F3 宽频数据：

```text
inline:    well_inline - 8  至 well_inline + 8
crossline: well_crossline - 16 至 well_crossline + 16
time:      保留完整有效时间范围
```

该窗口覆盖 `17 x 33` 个空间位置。训练样本可以从窗口内沿 inline 和 crossline 两个方向提取，但 patch 的所有有效空间位置必须完全落在标定窗口内，禁止跨越窗口边界后通过填充引入外部宽频数据。

### 3.3 留出井禁用区

每折留出井的以下区域在训练、验证、早停、checkpoint 选择和调参阶段均禁止读取宽频数据：

```text
inline:    heldout_inline - 16 至 heldout_inline + 16
crossline: heldout_crossline - 32 至 heldout_crossline + 32
```

禁用区大于标定窗口，用于阻断井旁相邻剖面和重叠 patch 造成的空间泄露。

此外，留出井的完整目标 inline 和完整目标 crossline 都不得作为宽频训练或验证平面。推理时可以读取其窄频输入；只有折内 checkpoint 冻结并生成哈希后，才允许读取该井对应宽频参考进行一次评价。

### 3.4 禁止使用

- 18 号实验模型权重；
- 18 号全区真实 F3 宽频训练样本；
- 留出井及其禁用区中的宽频标签；
- 留出井评价结果参与该折或其他折的超参数调整；
- 根据四折中某一折的测试表现单独修改该折配置；
- 随机拆分相互重叠的 patch 到训练集和验证集。

## 5. 公共预训练

公共预训练使用 20 号方案的数据思想，但不直接继承 20 号训练权重：

1. F3 窄频多频带遮蔽自监督，用于学习实际工区的相位、同相轴连续性和噪声统计；
2. 测井约束合成残差监督，用于提供 35 Hz 以上外推目标；
3. 不读取任何 F3 实际宽频目标；
4. 使用统一配置训练一次基础模型；
5. 根据 F3 已知频带自监督验证和合成验证选择公共预训练 checkpoint。

公共预训练 checkpoint 的元数据必须包含：

```text
uses_f3_wide_target = false
stage = common_pretraining
checkpoint_sha256
training_data_manifest
```

## 6. 局部宽频样本

### 6.1 样本定义

局部标定窗口内：

```text
wide_raw = 标定窗口中的 F3 宽频数据
narrow_raw = lowpass(wide_raw, 3-6-25-35 Hz)
scale = P99(abs(narrow_raw))
input_norm = narrow_raw / scale
residual_label = (wide_raw - narrow_raw) / scale
```

输入不裁剪，标签不添加噪声。训练增强只允许左右翻转，不允许时间轴翻转。

### 6.2 Patch 规则

由于单个标定窗口在 inline 方向只有 17 个、crossline 方向只有 33 个空间位置，局部宽频样本使用：

```text
time patch size = 256
spatial patch size = 32
time stride = 128
spatial stride = 8
```

网络继续接受二维 patch。空间宽度不足 32 时，只允许在标定窗口内部进行反射填充；元数据必须记录原始有效宽度和填充宽度。

公共预训练仍可使用 `256 x 256` patch。模型为全卷积结构，因此微调和推理可以接受不同空间宽度。

### 6.3 训练和验证划分

每个标定井窗口沿 inline 坐标划分互不重叠的训练子区和验证子区：

- 相对井位偏移 `-8` 至 `+6` 的 15 个 inline 平面用于微调训练；
- 相对井位偏移 `+7` 和 `+8` 的 2 个 inline 平面作为局部宽频验证平面；
- 训练用 crossline 方向 patch 只能使用上述 15 个训练 inline 位置，不得跨入两个验证平面；
- 验证样本从两个完整验证 inline 平面提取，不与训练 patch 共享空间位置；
- 四折全部使用同一侧的固定划分规则，避免按验证结果改变边界；
- 三口标定井的验证指标按样本数加权平均。

验证集只来自当前折允许使用的三口标定井，不读取留出井宽频。

## 7. 模型和训练流程

### 7.1 模型

继续使用 18/20 号实验验证过的单通道 UNet-CBAM 残差网络和可微频率投影器：

```text
residual_pred = projector(network(narrow_input))
wide_pred = narrow_input + residual_pred
```

不使用 18 号模型权重，不增加第二个地震输入通道。

### 7.2 微调策略

每折从同一个公共预训练 checkpoint 初始化，分两个阶段：

**阶段 A：局部标定适配**

- 60 轮；
- 局部宽频标定样本占 60%；
- 测井合成残差样本占 20%；
- F3 窄频自监督样本占 20%；
- AdamW，初始学习率 `1e-4`；
- 公共预训练编码器前两层在前 10 轮冻结，之后全部解冻。

**阶段 B：低学习率联合稳定**

- 最多 40 轮；
- 三类样本比例保持不变；
- 初始学习率 `3e-5`；
- `ReduceLROnPlateau`；
- 早停耐心值 12；
- 最少训练到第 15 轮后才允许早停。

四折训练配置必须完全相同。任何基于留出井评价结果的单折返调均视为泄露。

## 8. 损失函数

### 8.1 局部宽频标定样本

- 高频残差 Smooth L1；
- 25-80 Hz 逐道相关损失；
- 多尺度局部复数 STFT 损失；
- 横向梯度一致性损失；
- 重组宽频波形 Smooth L1；
- 0-22 Hz 泄漏损失。

相较 18 号，局部标定微调提高逐道相关和复数 STFT 相位项权重，降低单纯对数振幅频谱项权重，避免只匹配平均频谱。

### 8.2 合成样本

继续使用完整高频残差监督，保持未标定频段的外推能力。

### 8.3 F3 窄频自监督样本

只在已知遮蔽频带计算损失，不产生 35 Hz 以上伪标签，用于抑制局部标定微调导致的实际域结构遗忘。

## 9. Checkpoint 选择和泄露防护

每折 checkpoint 只根据以下折内验证指标选择：

1. 三口标定井局部宽频验证残差相关性；
2. 三口标定井局部宽频验证加权相位分数；
3. 局部宽频重组相关性；
4. F3 窄频自监督验证相关性；
5. 0-22 Hz 泄漏比例。

门控规则：

```text
局部验证残差相关性 > 0
局部验证相位分数 > 0
F3 窄频自监督相关性 >= 公共预训练 checkpoint 的 95%
低频泄漏比例 <= 0.01
```

满足门控后，优先选择局部验证残差相关性最高的 checkpoint；相差不超过 0.01 时选择相位分数更高者。

每折冻结后保存：

- checkpoint SHA256；
- 公共预训练 checkpoint SHA256；
- 三口标定井列表；
- 留出井；
- 标定窗口和禁用区；
- 训练/验证平面清单；
- `uses_heldout_well_wide_target=false`；
- 所有门控指标。

推理脚本必须先验证折内模型锁和数据清单，再允许读取留出井宽频参考。

## 10. 推理与评价

每折只预测留出井：

```text
fold_well1: inline 244, crossline 336
fold_well2: inline 362, crossline 387
fold_well3: inline 442, crossline 848
fold_well4: inline 722, crossline 1007
```

每个剖面输出：

- 窄频输入；
- 预测高频残差；
- 直接重组结果；
- 残差高通后重组结果；
- 冻结后读取的宽频参考；
- 误差剖面；
- 共享色标对比图；
- 平均频谱和 35-80 Hz 局部频谱。

每折分别报告：

- MAE、RMSE、PSNR；
- 全频相关系数；
- 25-80 Hz 带通相关系数；
- 实际高频残差相关系数；
- 加权相位分数；
- 高频包络相关系数；
- 35-80 Hz 能量比例；
- 频谱 L1；
- 0-22 Hz 相关系数和 NRMSE。

最终报告包含：

1. 四折逐井指标；
2. 四个 inline 的汇总指标；
3. 四个 crossline 的汇总指标；
4. 直接重组与高通重组比较；
5. 低通基线、18 号上限实验、20 号无宽频监督实验的横向对照。

18 号只作为“全区宽频监督上限”对照，不能与 21 号宣称为相同数据条件。

## 11. 成功标准

21 号实验判定成功必须同时满足：

- 四折平均 inline 全频相关性高于对应低通基线；
- 四折平均 crossline 全频相关性高于对应低通基线；
- 四折平均实际高频残差相关性为正；
- 四折平均加权相位分数为正；
- 至少 3/4 留出井的直接重组相关性不低于各自低通基线；
- 0-22 Hz 相关性不低于 0.995；
- 0-22 Hz NRMSE 不高于 0.02；
- 频谱改善不能以整体相关性和 RMSE 恶化为代价。

如果只增加 35-80 Hz 能量但高频相关性、相位或整体相关性不达标，实验判定为失败。

## 12. 测试与审计

实现前先编写测试，至少覆盖：

- 四折中每口井恰好被留出一次；
- 每折恰好使用另外三口井作为标定井；
- 局部宽频样本完全位于 `inline ±8、crossline ±16` 窗口；
- 留出井 `inline ±16、crossline ±32` 禁用区没有宽频训练或验证样本；
- 训练和验证平面不重叠；
- 留出井完整 inline/crossline 不参与宽频训练；
- 公共预训练不读取 F3 宽频目标；
- 四折均从同一公共预训练 SHA 初始化；
- 四折配置完全一致；
- checkpoint 选择不读取留出井评价指标；
- 模型锁能够检测 checkpoint 或数据清单修改；
- 标签严格等于宽频减低通输入；
- 归一化使用窄频 P99；
- 不存在时间轴上下翻转；
- 推理输出保持低频主体；
- 每折只评价其留出井；
- 汇总报告使用四折冻结结果，不进行单折返调。

所有 Python 命令使用 `D:\Anaconda\python.exe`。
