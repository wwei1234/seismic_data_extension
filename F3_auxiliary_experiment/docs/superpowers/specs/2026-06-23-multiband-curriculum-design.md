# 20号多频带课程联合训练设计

## 1. 目标

创建 `20_curriculum_multiband` 实验。重复利用可获得的 F3 窄频数据构造多频带
遮蔽自监督任务，同时使用测井约束合成宽频样本训练 35 Hz 以上的外推能力。

本轮优先解决 19 号实验中“频谱能量增加，但预测残差与真实残差相关性和相位分数
接近零”的问题。网络必须先在 F3 已知频带内证明能够恢复位置正确、相位一致的成分，
再逐步学习未知高频外推。

## 2. 数据使用边界

### 2.1 允许参与训练和验证

- F3 实际窄频数据及其振幅包络；
- 同一 F3 窄频数据经过不同低通、带阻和频带遮蔽形成的自监督样本；
- 井旁 F3 窄频地震道、井震匹配结果和估计子波；
- 测井反射系数；
- 测井反射系数与估计/B-spline 子波生成的完全合成宽频数据；
- 由合成宽频低通得到的合成窄频输入及其残差标签。

### 2.2 禁止参与训练和验证

- F3 实际宽频数据作为输入、标签、损失目标或伪标签；
- F3 实际宽频数据参与调参、早停、checkpoint 选择和训练轮数选择；
- 18 号实验的真实宽频监督样本或模型权重；
- 19 号最终盲评结果反向用于逐次试探 20 号超参数。

F3 实际宽频数据只能在模型、频带配置和 checkpoint 全部锁定后读取，用于一次性
四井 inline/crossline 盲评。

## 4. F3多频带遮蔽自监督样本

### 4.1 基础数据

从 F3 SEG-Y 按正确几何读取剖面，对每个剖面生成 3-6-25-35 Hz 窄频数据。按
`256 x 256` 切片，步长为 128，并覆盖剖面末端。训练和验证按空间剖面分组，验证
剖面不得与训练 patch 重叠。

每个 patch 使用自身干净窄频数据绝对值 P99 归一化。标签不含额外噪声，只允许在
输入端加入 0、0.01 或 0.03 的噪声。

### 4.2 重复遮蔽任务

同一窄频 patch 每次训练时动态随机选择一种任务，而不是只离线保存一个固定版本。

| 任务 | 网络输入 | 已知目标残差 | 用途 |
|---|---|---|---|
| A | 3-12/16 Hz 低通 | 输入到 20 Hz 窄频之间的差 | 学习低频到中频的确定性恢复 |
| B | 3-18/22 Hz 低通 | 输入到 28 Hz 窄频之间的差 | 学习中频相位延续 |
| C | 3-22/26 Hz 低通 | 输入到 35 Hz 窄频之间的差 | 最接近最终拓频边界 |
| D | 原窄频随机遮蔽 4-10 Hz 连续频带 | 被遮蔽的已知频带 | 防止只记忆固定截止频率 |

表中斜线表示余弦渐变的 stop/pass 边界。例如任务 C 使用约 22 Hz 停止、26 Hz
通过的低通输入。具体截止频率在每个任务规定边界附近随机抖动 1-2 Hz。

F3 自监督输出只在本任务被遮蔽且原始窄频中真实存在的频带计算损失。不得要求该类
样本预测 35 Hz 以上未知内容。

计划生成 3000-5000 个基础 patch；动态任务和随机频率使每个基础 patch 在不同
epoch 中形成多个不同训练对。

## 5. 测井约束合成样本

沿用 16 号经过几何修正的样本生成规则：

- 使用四口井反射系数及 2 井、3 井、4 井组合；
- 保持实际井 crossline 相对位置；
- 沿横向线性插值并允许井外边界外推；
- 构造褶皱、局部隆起和倾斜断层；
- 时间方向使用线性插值；
- 横向执行 `size=5` 平滑；
- 宽频子波同时包含井震估计子波和 B-spline 扰动子波；
- 合成窄频输入必须由合成宽频低通得到；
- 输入噪声水平使用 0.01 和 0.03，标签不含噪声；
- 使用窄频输入 P99 作为输入、宽频和残差的共同尺度。

合成标签为：

```text
residual_label = clean_wide - clean_narrow
```

计划生成 2000-3000 个 patch。验证集按井组合和结构参数分组，避免同一合成剖面的
相邻 patch 同时进入训练集和验证集。

## 6. 网络与输出

继续使用单通道 UNet-CBAM，不增加双通道，不改变网络主体。

网络预测残差：

```text
residual_pred = model(masked_or_narrow_input)
wide_pred = narrow_input + residual_pred
```

训练时根据样本类型应用不同的频率投影：

- F3 自监督样本：只保留当前遮蔽任务的已知目标频带；
- 合成样本：保留约 22-100 Hz，32-38 Hz 平滑进入主要外推频带，85-100 Hz
  平滑衰减；
- 最终 F3 推理：保留 32-100 Hz 的预测残差并加回原始窄频输入。

滑窗融合完成后再次执行整剖面频率投影，防止窗口融合重新产生低频泄漏。

## 7. 联合课程训练

总训练轮数为 300，batch size 为 4。

### 阶段一：真实域相位基础，1-60轮

- 仅使用 F3 多频带自监督样本；
- A、B、C、D 四种任务均匀采样；
- 初始学习率 `5e-4`；
- 目标是让网络在真实 F3 已知频带内学会相位和同相轴连续性。

### 阶段二：真实域优先的联合训练，61-180轮

- F3 自监督 batch 与测井合成 batch 按 2:1 采样；
- 学习率 `3e-4`，根据验证平台自动衰减；
- F3 样本仅计算已知遮蔽频带损失；
- 合成样本计算完整残差外推损失；
- 每完成一个合成 batch，后续两个 batch 使用 F3 自监督，抑制合成域遗忘。

### 阶段三：平衡联合微调，181-300轮

- F3 与合成 batch 按 1:1 采样；
- 学习率 `1e-4`，最低衰减至 `1e-6`；
- 增强合成高频外推，但继续用 F3 真实域任务约束相关性和相位；
- 不允许切换为纯合成训练。

## 8. 损失函数

### 8.1 F3自监督损失

只在被遮蔽的已知频带计算：

- 残差 Smooth L1；
- 逐道带通相关损失；
- 复数 STFT 损失；
- 横向梯度损失；
- 非目标频带泄漏损失。

相关损失权重高于 19 号实验，确保模型不能只匹配频谱幅值。

### 8.2 合成监督损失

- 合成残差 Smooth L1；
- 逐道 25-80 Hz 相关损失；
- 复数 STFT 相位与振幅损失；
- 重组宽频波形损失；
- 横向梯度和低频泄漏损失。

两类样本使用同一个网络参数，但使用各自的目标频带掩码，避免 F3 已知频带任务与
合成未知高频任务相互矛盾。

## 9. 验证与checkpoint选择

每个 epoch 分别记录：

### F3遮蔽验证

- 被遮蔽频带逐道相关系数；
- 加权相位分数；
- 包络相关系数；
- 重建窄频全频相关系数；
- 非目标频带泄漏比例。

### 合成宽频验证

- 残差 25-80 Hz 相关系数；
- 加权相位分数；
- 重组宽频相关系数；
- 频谱 L1；
- MAE 和 RMSE。

checkpoint 选择采用门控规则，而不是将所有指标简单相加：

1. F3 遮蔽验证平均相关系数必须达到至少 0.85；
2. F3 遮蔽验证相位分数必须达到至少 0.80；
3. F3 非目标频带泄漏不得超过目标残差能量的 3%；
4. 满足前三项后，在候选模型中选择合成残差相关性最高者；
5. 若合成残差相关性相差不超过 0.01，选择 F3 遮蔽相关性更高者。

如果训练结束仍未达到 F3 门槛，则不进行 F3 宽频盲评，先报告训练失败并分析原因。
F3 遮蔽相关性只验证已知频带恢复能力，不能被解释为 35 Hz 以上真实高频正确。

## 10. 模型锁与盲评

训练完成后保存：

- checkpoint SHA256；
- 数据清单和样本元数据摘要；
- 三阶段训练配置；
- F3 遮蔽验证与合成验证最佳指标；
- `uses_f3_wide_target=false`；
- checkpoint 选择原因。

锁文件生成后才允许读取 F3 宽频参考。盲评剖面为：

```text
inline:    244, 362, 442, 722
crossline: 336, 387, 848, 1007
```

同时输出：

- 原始窄频输入；
- 预测残差；
- 直接重组结果；
- 高通残差重组结果；
- F3 宽频参考；
- 共用色标剖面对比；
- 平均频谱和 35-80 Hz 局部频谱。

评价指标包括 MAE、RMSE、PSNR、全频相关系数、25-80 Hz 带通相关性、实际残差
相关性、加权相位分数、包络相关性、高频能量比例和频谱 L1。

成功标准不是只看频谱扩展。至少应满足：

- direct 或 highpass 重组的全频相关性不低于窄频基线；
- 实际残差 25-80 Hz 相关性明显高于 19 号的接近零结果；
- 加权相位分数为稳定正值；
- inline 与 crossline 均不能仅靠个别剖面改善。

## 11. 测试与审计

实现前先编写测试，覆盖：

- 动态遮蔽标签严格等于原窄频减遮蔽输入；
- F3 自监督标签在 35 Hz 以上没有目标能量；
- 合成标签严格等于宽频减窄频，且不减带噪输入；
- 训练采样比例符合各课程阶段；
- F3 和合成样本使用正确的频带投影；
- checkpoint 门控规则拒绝高合成指标但低 F3 相关性的模型；
- 泄露防护拒绝任何 F3 宽频训练路径；
- 模型锁可检测 checkpoint 修改；
- 不存在时间轴上下翻转；
- 归一化均使用窄频 P99。

所有训练、推理和评价命令使用 `D:\Anaconda\python.exe`。
