# F3 Experiment 18 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and evaluate a phase-consistent F3 bandwidth-extension experiment using spatially guarded real F3 pseudo-pairs, synthetic residual priors, a hard low-frequency bypass, and local complex spectral constraints.

**Architecture:** Experiment 18 keeps the shared single-channel UNet-CBAM but projects its output into 22-100 Hz before adding it to the untouched narrow-band input. Training combines real F3 residual patches extracted outside guarded well inline/crossline planes with experiment 16 synthetic residual patches. Evaluation adds high-band waveform correlation, weighted phase score, envelope correlation, and low-frequency preservation metrics.

**Tech Stack:** Python 3, NumPy, SciPy, PyTorch 2.8, SEG-Y geometry reader, pytest, matplotlib.

```python
def cosine_frequency_mask(nt, dt, low_stop=22, low_pass=28,
                          high_pass=85, high_stop=100, device=None, dtype=None):
    ...


def project_frequency_band(x, dt=0.004):
    spectrum = torch.fft.rfft(x, dim=-2)
    mask = cosine_frequency_mask(x.shape[-2], dt, device=x.device, dtype=x.dtype)
    return torch.fft.irfft(spectrum * mask.view(1, 1, -1, 1),
                           n=x.shape[-2], dim=-2)


class PhaseConsistentResidualModel(nn.Module):
    def forward_with_residual(self, x):
        residual = project_frequency_band(self.net(x), self.dt)
        return x + residual, residual
```
