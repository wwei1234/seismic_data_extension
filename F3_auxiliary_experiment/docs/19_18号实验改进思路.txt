18号实验改进思路：真实F3留出式训练与相位一致高频旁路
========================================================

日期：2026-06-23

一、本轮只解决的新问题
----------------------

16号和17号已经证明，现有网络能够增加35～80 Hz能量并改善平均频谱，但新增
高频的相位、振幅和同相轴位置与实际F3宽频参考不一致，导致MAE、RMSE和相关
系数下降。

本轮不再调整合成构造参数，而是直接解决两个核心问题：

1. 合成样本与实际F3数据之间的振幅、相位、噪声和横向相干性域差异。
2. 全局平均频谱损失不能约束高频能量出现在哪个时间和横向位置。


二、备选方案比较
----------------

方案A：继续使用16号纯合成残差样本，只增加局部相位损失。

优点是训练定义干净，不使用实际宽频数据训练。缺点是子波、噪声、相位和
横向相干性的域差异仍然存在，预计只能有限改善。

方案B：使用经典谱整形或确定性反褶积。

优点是低频和相位较稳定，结果可解释。缺点是输入在35 Hz以上接近无有效
能量，线性滤波无法可靠恢复被完全压制的频率，拓频上限较低。

方案C：真实F3留出式伪配对训练，并保留合成样本作为结构先验。

将实际F3原始数据作为宽频标签，将其低通结果作为输入，但严格排除四口井
评价inline、crossline及邻域。该方案能直接学习F3自身的子波、相位、振幅
和噪声统计，同时通过空间隔离避免评价数据泄漏。

本轮选择方案C。

四、真实F3样本的空间隔离
------------------------

评价面保持不变：

    inline：244、362、442、722
    crossline：336、387、848、1007

训练样本从其他F3 inline和crossline提取。任何训练patch只要与上述评价面或
保护带相交，就必须丢弃。

保护带默认设置：

    inline方向：评价inline两侧各8条
    crossline方向：评价crossline两侧各16条

训练patch同时从两种方向提取：

    inline section：time × crossline
    crossline section：time × inline

这样可降低只用inline训练后对crossline泛化较差的问题。训练、验证按完整
空间平面划分，不能随机拆分相互重叠的patch。

真实样本定义：

    wide_raw = 实际F3原始剖面
    narrow_raw = lowpass(wide_raw, 3-6-25-35 Hz)
    scale = P99(abs(narrow_raw))
    input = clip(narrow_raw / scale, -1, 1)
    residual_label = (wide_raw - narrow_raw) / scale

真实样本不额外添加白噪声。16号合成残差样本继续参与训练，用于保持井约束
和结构扰动覆盖，但训练采样时真实样本占主要比例。


五、模型输出与低频硬保护
------------------------

网络主体继续使用单通道UNet-CBAM，不引入双通道。

网络只预测高频分量。原始网络输出必须经过可微分频率投影：

    0～22 Hz：严格为0
    22～28 Hz：余弦渐入
    28～85 Hz：保留
    85～100 Hz：余弦渐出
    100 Hz以上：严格为0

最终结果：

    predicted_residual = frequency_projector(network(input))
    wide_prediction = input + predicted_residual

推理反归一化后：

    wide_prediction_raw = narrow_raw + predicted_residual * narrow_scale

因此网络不能修改主要低频主体，不再依赖零均值操作或推理后经验高通。


六、损失函数
------------

本轮损失只围绕“高频位置是否正确”设计：

1. 高频残差Smooth L1
   约束预测残差与真实残差的逐点波形。

2. 多尺度局部复数频谱损失
   沿时间轴使用64、128、256采样点窗口计算STFT，在25～80 Hz内同时比较
   实部、虚部和对数振幅。局部复数谱直接约束高频出现的时间位置和相位，
   不再只比较整张patch的平均振幅谱。

3. 高频带通相关损失
   对25～80 Hz预测残差和标签计算逐trace归一化相关性，惩罚相位反转和
   时间错位。

4. 横向结构梯度损失
   比较相邻trace之间的高频差分，约束同相轴连续性，抑制细碎随机纹理。

5. 低频泄漏损失
   检查预测残差0～22 Hz能量。虽然模型已有硬投影，该项用于监控数值误差。

模型选择以真实F3空间验证集的复合损失为主，不再以合成验证损失单独决定。


七、训练安排
------------

第一阶段采用真实F3样本与16号合成残差样本混合训练：

    batch size：4
    优化器：AdamW
    初始学习率：5e-4
    混合精度：开启
    最大轮数：120
    学习率调度：ReduceLROnPlateau
    early stopping：30轮
    左右翻转：允许
    上下翻转：禁止

每个batch通过加权采样提高真实F3样本比例，目标约为真实样本70%、合成样本
30%。保存best_model和last_model。


八、评价指标与通过标准
----------------------

四口井inline和crossline必须分别评价：

1. 全频MAE、RMSE、PSNR和Correlation。
2. 35～80 Hz能量比例和平均频谱L1。
3. 25～80 Hz带通波形相关系数。
4. 25～80 Hz幅值加权相位一致性：

       phase_score =
       sum(|P||T|cos(angle(P)-angle(T))) / sum(|P||T|)

5. 高频包络相关系数。
6. 预测结果3～22 Hz与低通输入的相关系数及归一化误差。

本轮目标：

    低频保护相关系数 >= 0.995
    inline全频Correlation >= 低通基线0.613888
    crossline全频Correlation >= 低通基线0.588366
    inline和crossline频谱L1均 <= 0.20
    25～80 Hz带通相关性和phase_score必须为正，并明显高于16/17号结果

频谱达标但全频相关性或高频相位不达标时，本轮判定为失败。


九、失败后的自动分支
--------------------

若18号频谱改善但高频相关性仍低：

    下一轮优先增加反射系数/宽频子波物理分解，网络预测反射系数修正量。

若高频相位改善但能量不足：

    下一轮调整频带能量校准和局部对数振幅损失，不修改低频旁路。

若inline明显好于crossline：

    下一轮增加方向均衡采样或方向共享的局部算子。

若训练集和验证集差距较大：

    下一轮减少模型容量、扩大真实空间留出并加强幅值增广。


十、预期判断
------------

18号实验是从“合成先验驱动”转向“实际F3统计校正”的第一轮。它不能证明
真实缺失高频具有唯一解，但能够严格检验：在不接触四井评价面的条件下，
同一工区其他区域是否提供足够稳定的相位和构造先验，使拓频结果同时超过
低通基线的相关性并改善目标频带。
