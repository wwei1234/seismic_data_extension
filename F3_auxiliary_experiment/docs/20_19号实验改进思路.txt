19号实验改进思路：无F3宽频监督的测井合成与窄频自监督
====================================================

日期：2026-06-23

一、数据使用边界
----------------

允许使用：

1. 测井反射系数、测井曲线和井位信息。
2. F3实际窄频数据及其振幅包络。
3. 井旁窄频地震道、井震匹配结果和据此得到的估计子波。
4. 完全由测井反射系数和人工/估计子波生成的合成宽频标签。

禁止使用：

1. F3实际宽频数据作为训练或验证标签。
2. F3实际宽频数据参与损失计算、调参、早停和checkpoint选择。
3. 18号由实际F3宽频数据生成的训练样本及其模型权重。
4. 最终盲评结果反向用于修改19号模型。

F3宽频数据只允许在模型、配置和checkpoint全部锁定后读取一次，用于最终
四井inline/crossline盲评。


二、现有可复用数据判断
----------------------

16号合成样本满足本轮数据边界：

- 反射系数来自测井数据；
- 宽频标签由测井反射系数与B-spline子波卷积生成；
- F3仅用于低通振幅包络；
- 估计子波仅用于确定子波长度，实际标签使用人工B-spline子波；
- 没有把F3实际宽频剖面作为标签。

因此19号可以读取16号合成训练/验证数组，但不能读取18号真实F3训练样本。


三、两阶段训练
--------------

阶段A：F3窄频自监督预训练

1. 从F3数据生成并缓存3～35 Hz窄频数据。
2. 再将窄频数据低通到约18～22 Hz，作为网络输入。
3. 标签为窄频数据减去进一步低通数据，即实际已知的约18～35 Hz成分。
4. 临时输出投影频带为16～40 Hz。
5. 该阶段只学习F3实际振幅、噪声、横向连续性和相位统计，不接触未知高频。

阶段B：测井合成高频残差监督

1. 使用16号测井约束合成样本。
2. 输入为合成低通数据，标签为合成宽频减合成低通。
3. 输出投影改为32～100 Hz，避免推理时重复添加输入中已有的25～35 Hz。
4. 使用局部复数STFT、残差波形、带通相关和横向梯度损失。
5. checkpoint仅根据合成验证集选择。


四、模型和推理
--------------

网络继续使用单通道UNet-CBAM。

最终输出：

    residual = project_32_100(network(narrow_input))
    prediction = narrow_input + residual

0～32 Hz由原始窄频输入硬旁路保留，32～38 Hz余弦渐入，85～100 Hz渐出。
滑窗融合完成后再次对整张残差做全局频率投影，防止融合窗重新产生低频。


五、泄露防护
------------

1. 训练脚本不得导入SEG-Y读取器。
2. 训练脚本不得读取任何名称含wide_reference、wide_prediction或18号真实样本
   的文件。
3. 自监督样本文件只保存extra-lowpass输入和已知窄频残差标签。
4. 训练结束后生成lock文件，保存checkpoint SHA256、配置和训练历史摘要。
5. 最终评价脚本必须验证lock文件与checkpoint哈希一致后才能读取F3参考。


六、训练与模型选择
------------------

阶段A：

    epochs = 40
    batch size = 4
    learning rate = 5e-4
    数据 = F3窄频自监督patch

阶段B：

    epochs = 200
    batch size = 4
    learning rate = 3e-4
    数据 = 16号测井约束合成残差patch

阶段B从阶段A权重初始化。最佳模型只按阶段B合成验证损失选择。


七、最终盲评
------------

锁定后评价：

    inline：244、362、442、722
    crossline：336、387、848、1007

评价指标与18号一致：

- MAE、RMSE、Correlation；
- 35～80 Hz能量比例和频谱L1；
- 实际残差25～80 Hz相关性；
- 实际残差幅值加权相位分数；
- 高频包络相关性；
- 0～30 Hz低频保持。

本轮结果必须明确标注为“无F3宽频监督盲评”，并与16号纯合成残差基线以及
18号有宽频工区监督结果同时对比。
