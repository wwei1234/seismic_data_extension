地震数据拓频实验过程总结
================================================================================

一、整个地震数据拓频思路
--------------------------------------------------------------------------------

本实验的核心目标是：利用深度学习方法，将窄频带地震记录拓展为更接近宽频带地震记录的结果。

整体技术路线不是直接拿 F3 实际地震数据作为训练标签，而是采用“井控合成训练 + F3 实际数据测试”的辅助实验思路：

1. 利用测井数据计算波阻抗 AI，再由 AI 序列计算反射系数序列。

2. 利用井旁地震道和井反射系数估计地震子波。
   当前代码中使用频率域反褶积估计统计子波：

       W(f) = S(f) * conj(R(f)) / (|R(f)|^2 + water_level)

   其中 R(f) 是井反射系数频谱，S(f) 是井旁地震道频谱。

3. 得到宽频带子波和窄频带子波。
   当前频带设置为：

       窄频输入：3-6-25-35 Hz
       宽频目标：3-6-55-75 Hz

   窄频子波用于生成网络输入，宽频子波用于生成网络标签。

4. 用测井反射系数和子波褶积生成合成地震记录。

       窄频合成记录 = 反射系数 * 窄频子波
       宽频合成记录 = 反射系数 * 宽频子波

5. 在合成记录上加入构造扰动、横向变化、随机噪声和 Q 衰减等，使训练样本更接近真实地震剖面。

6. 网络训练阶段：
   输入为窄频合成记录，标签最初为宽频合成记录；后续改为预测高频残差。

7. 实际测试阶段：
   将 F3 工区原始地震数据视为宽频参考，对其进行低通滤波得到窄频输入，再送入网络进行拓频预测。

8. 评价阶段：
   以 F3 原始地震数据作为宽频参考，对比：

       低通输入 vs 原始 F3
       网络预测结果 vs 原始 F3

   评价指标包括 MAE、RMSE、相关系数、PSNR、频谱 L1 差异、35-80 Hz 高频能量占比等。


二、逐轮实验总结
--------------------------------------------------------------------------------

第 1 轮：明确主实验和辅助实验思路
----------------------------------

最初讨论的问题是：F3 工区数据本身频谱已经接近 0-80 Hz，按理说已经属于较宽频数据，不能直接把它当作“窄频输入”进行监督训练。

因此确定采用辅助实验思路：

    训练集：由测井反射系数和宽/窄频子波褶积生成
    测试集：F3 原始数据低通滤波后输入网络
    参考标签：F3 原始数据本身

这一轮明确了实验逻辑：

    合成数据负责监督训练；
    F3 数据负责验证实际拓频效果。


第 2 轮：井震匹配和子波估计
--------------------------

这一轮重点处理“宽频带子波和窄频带子波如何得到”的问题。

当前代码中，先根据井位置找到对应的 F3 井旁地震道，然后用井反射系数和井旁地震道进行频率域反褶积，得到统计子波。

需要注意的是：当前提取的子波不是严格零相位子波。

原因是代码中保留了估计子波的相位：

    phase = np.angle(wavelet_spec)
    wavelet_spec = amp * np.exp(1j * phase)

后续只是对子波做了居中、去均值、加窗和极性统一。这会让子波看起来接近零相位，但数学上没有强制相位为 0。

因此当前子波更准确的表述是：

    由井反射系数和井旁地震道估计得到的、经过居中和频谱整形的带相位统计子波。

如果后续要严格零相位，需要将频谱相位强制设为 0，或者对子波做偶对称化处理。


第 3 轮：直接宽频预测实验
------------------------

最初训练方式是：

    输入：窄频合成记录
    标签：宽频合成记录
    网络输出：宽频预测结果

这种方式比较直接，但问题也明显：

1. 网络需要同时学习低频背景和高频细节。
2. 低频背景其实已经存在于窄频输入中，让网络重新预测全频结果容易造成幅度不稳定。
3. 在 F3 实际数据上，预测结果和原始宽频参考的相关性偏低。

因此后续转向残差预测。


第 4 轮：方案二，残差预测
------------------------

这一轮建立了 residual_prediction_experiment。

核心思想是：

    residual = wide_label - narrow_input
    wide_prediction = narrow_input + network(narrow_input)

也就是说，让网络只学习宽频标签相对窄频输入缺失的部分。

训练结果：

    训练到 300 轮之前，曾中断在 114 轮；
    后续继续训练到 200 轮；
    最佳验证损失出现在第 200 轮附近：
    best_val_loss = 0.072280

F3 实际数据评价结果大致为：

    低通输入 vs 原始 F3：
        Corr = 0.5910
        MAE  = 1430.19
        RMSE = 2005.84

    残差预测 vs 原始 F3：
        Corr = 0.2084
        MAE  = 2453.45
        RMSE = 3075.77
        35-80 Hz 高频能量占比 = 0.3796

这一轮发现的问题：

1. 网络确实补出了较多高频能量。
2. 但是预测剖面出现明显低频/DC 偏置，整体偏负，图像上表现为大面积偏蓝。
3. 时域误差明显变大，相关系数下降。

结论：

    纯残差预测比直接宽频预测更符合思路，但如果不约束残差的低频/DC 分量，网络会把低频偏置也加入结果中。


第 5 轮：方案三，高通约束残差预测
--------------------------------

针对残差预测中出现的低频偏置，提出将网络输出限制在补频频带。

建立 highpass_residual_experiment。

核心设置：

    窄频输入：3-6-25-35 Hz
    残差输出约束：25-35-55-75 Hz
    宽频目标：3-6-55-75 Hz

训练逻辑：

    residual_label = bandpass(wide_label - narrow_input, 25-35-55-75 Hz)
    raw_residual = network(narrow_input)
    residual_prediction = bandpass(raw_residual, 25-35-55-75 Hz)
    wide_prediction = narrow_input + residual_prediction

训练到 300 轮：

    best_epoch = 265
    best_val_loss = 0.393746

注意：该 loss 与方案二不能直接比较，因为 loss 结构已经改变，输出被带通滤波限制。

F3 实际数据评价：

    高通约束残差预测 vs 原始 F3：
        Corr = 0.5515
        MAE  = 1481.49
        RMSE = 2071.52
        35-80 Hz 高频能量占比 = 0.1848
        频谱 L1 = 0.2718

这一轮的效果：

1. 明显压制了方案二中的整体偏蓝/偏负问题。
2. 时域指标接近低通输入，相关性明显好于方案二残差预测。
3. 但高频补充变得保守，35-80 Hz 高频能量仍远低于 F3 原始宽频参考。

这一轮发现的新问题：

    将高通滤波放在 loss 之前，会截断低频分量的梯度约束。网络可能仍然产生低频偏置，只是被滤波器掩盖，不能从根本上让网络学会零均值残差。


第 6 轮：偏置修正方案
--------------------

根据 偏置修正.txt 中的方案，建立 bias_correction_experiment。

核心思想：

    不再把高通滤波放在 loss 计算之前；
    训练阶段保留完整残差梯度；
    通过结构和 loss 共同约束残差均值；
    推理阶段再做高通/补频带通滤波作为后处理兜底。

具体实现：

1. 网络输出后强制零均值：

       out = out - out.mean(dim=(-2, -1), keepdim=True)

2. loss 中加入残差均值约束：

       loss_mean = abs(pred_residual.mean()).mean()

3. 总 loss：

       loss = wide_loss + 0.2 * residual_l1 + 0.1 * mean_loss

4. 训练阶段不在 loss 前做高通滤波。

5. 推理阶段对预测残差做 25-35-55-75 Hz 滤波，再加回窄频输入。

训练结果：

    训练 300 轮；
    best_epoch = 294
    best_val_loss = 0.204689
    val_mean ≈ 4.4e-08

说明残差均值约束有效，网络输出残差的均值已经接近 0。

F3 实际数据评价：

    偏置修正预测 vs 原始 F3：
        Corr = 0.5715
        MAE  = 1456.74
        RMSE = 2038.95
        35-80 Hz 高频能量占比 = 0.1509
        频谱 L1 = 0.2750

与高通约束残差预测相比：

1. 相关系数略高。
2. MAE/RMSE 略好。
3. 偏置问题进一步缓解。
4. 高频补充仍然偏保守。


三、遇到的主要问题
--------------------------------------------------------------------------------

问题 1：F3 数据本身已经是宽频，不能直接作为窄频训练输入
------------------------------------------------------

F3 原始数据频谱已经接近 0-80 Hz，如果直接作为窄频输入，会导致实验逻辑不清晰。

解决方式：

    将 F3 原始数据作为宽频参考；
    对 F3 原始数据低通滤波生成实际测试输入；
    训练样本由测井反射系数和宽/窄频子波合成。


问题 2：宽频/窄频子波来源不明确
------------------------------

最初不清楚论文中宽频带子波和窄频带子波如何从实际数据得到。

当前实现方式：

    根据井位置提取井旁地震道；
    由测井 AI 计算反射系数；
    用反射系数和井旁地震道做频率域反褶积估计统计子波；
    再根据实际井旁地震道和低通井旁地震道的频谱，整形得到宽/窄频子波。

注意：

    当前子波不是严格零相位，而是带相位统计子波。


问题 3：直接预测宽频结果时，网络负担过重
--------------------------------------

直接让网络从窄频预测宽频，相当于既要保留低频背景，又要补高频细节。

问题：

    低频背景本来已经在输入中存在；
    网络重复预测全频信息容易造成幅度和相位不稳定。

解决方式：

    改为残差预测：
    wide_prediction = narrow_input + residual_prediction


问题 4：残差预测出现低频/DC 偏置
-------------------------------

方案二中，网络输出残差没有任何高频限制，也没有零均值约束。

结果：

    虽然补出了高频能量，但预测剖面出现明显整体偏负；
    图像表现为大面积偏蓝；
    时域误差增大，相关性下降。

解决方式：

    后续分别尝试：
    1. 残差带通约束；
    2. 输出零均值；
    3. loss 中加入均值约束；
    4. 推理阶段高通/带通后处理。


问题 5：高通滤波放在 loss 前不是最理想
------------------------------------

将网络输出先高通滤波，再计算 loss，可以从结果上压制低频偏置，但也带来一个问题：

    低频偏置分量被滤掉后，不再参与 loss；
    网络对这部分输出没有梯度约束；
    因此它可能只是被掩盖，而不是被真正消除。

解决方式：

    在偏置修正方案中，将高通滤波移到推理阶段；
    训练阶段通过输出减均值和均值 loss 直接约束网络残差。


问题 6：高频补充仍然偏保守
------------------------

无论高通约束方案还是偏置修正方案，都能缓解偏置问题，但补充的 35-80 Hz 高频能量仍明显低于 F3 原始宽频参考。

当前结果中：

    原始 F3 高频能量占比约为 0.5913；
    高通约束残差预测约为 0.1848；
    偏置修正预测约为 0.1509。

说明当前网络更倾向于保守补频，未能充分恢复 F3 中 40-70 Hz 的能量。


四、针对问题做出的调整
--------------------------------------------------------------------------------

调整 1：改用辅助实验路线
----------------------

从“直接用 F3 数据训练”改为：

    测井合成数据训练；
    F3 低通数据测试；
    F3 原始数据评价。


调整 2：补充井震标定和子波估计可视化
----------------------------------

增加了：

    极性搜索；
    时移搜索；
    最佳相关系数计算；
    每口井的子波估计流程图；
    井旁地震道和合成道对比。

这一步用于判断测井反射系数、井旁地震道和估计子波是否匹配。


调整 3：从宽频直接预测改为残差预测
--------------------------------

将网络目标从：

    narrow -> wide

改为：

    narrow -> wide - narrow

然后：

    wide_prediction = narrow + residual_prediction

这样让网络专注于补充缺失频带。


调整 4：加入残差带通约束
----------------------

设置残差频带：

    25-35-55-75 Hz

使网络只补窄频输入之外、宽频目标之内的部分。

效果：

    明显减少低频偏置；
    时域指标比未约束残差预测更稳定；
    但高频补充偏保守。


调整 5：将高通滤波从 loss 前移到推理阶段
--------------------------------------

根据偏置修正方案，不再在训练 loss 前过滤网络输出。

原因：

    训练阶段需要保留完整梯度，让网络知道低频偏置本身是错误的；
    推理阶段再用高通/带通滤波作为保险措施。


调整 6：网络输出强制零均值
------------------------

在网络输出后加入：

    out = out - out.mean(dim=(-2, -1), keepdim=True)

物理意义：

    高频残差应正负对称，均值接近 0；
    不应携带低频基线漂移。

效果：

    验证集残差均值约束收敛到 4.4e-08 附近；
    明显缓解残差偏置。


调整 7：loss 中加入均值约束
-------------------------

在 residual loss 中加入：

    loss_mean = abs(pred_residual.mean()).mean()

权重设置为：

    mean_weight = 0.1

作用：

    从优化目标层面惩罚残差均值偏移。


调整 8：保存并隔离不同实验文件夹
------------------------------

为了避免多轮实验互相覆盖，分别建立了：

    residual_prediction_experiment
    highpass_residual_experiment
    bias_correction_experiment

每个实验都包含：

    code/
    data/
    figures/
    checkpoints/
    logs/

并将大型输出加入 .gitignore，避免误上传到 GitHub。


五、当前结论
--------------------------------------------------------------------------------

1. 当前最合理的路线是：

       测井合成训练 + F3 低通测试 + F3 原始数据评价。

2. 直接预测宽频结果不如预测残差合理。

3. 单纯残差预测会产生低频/DC 偏置，需要额外约束。

4. 在 loss 前做高通滤波可以改善表面结果，但不一定从根本上消除网络低频偏置。

5. 目前较合理的方案是：

       输出零均值 + loss 均值约束 + 推理阶段残差带通后处理。

6. 该方案可以有效缓解偏置，使残差均值接近 0，剖面不再整体偏负。

7. 当前仍未解决的核心问题是：

       高频补充偏保守，35-80 Hz 能量不足。

8. 下一步更值得尝试的是：

       在保持零均值和带通约束的前提下，对残差高频能量进行增益校正；
       或在 loss 中提高高频幅度谱约束权重；
       或让合成训练数据的频谱分布进一步接近真实 F3。
