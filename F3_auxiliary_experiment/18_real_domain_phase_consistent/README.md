# 18_real_domain_phase_consistent

本实验使用空间隔离的真实 F3 低通/宽频伪配对与 16 号合成残差样本混合训练。

- 四口井 inline、crossline 及保护带不参与训练。
- UNet-CBAM 只预测 22-100 Hz 高频分量。
- 最终输出通过低频旁路与输入相加，硬保护原始低频主体。
- 评价同时检查全频相关性、局部高频相关性、相位一致性和频谱距离。

增量设计见 `../docs/19_18号实验改进思路.txt`。

## 最终结果

- 真实 F3 样本：训练 2400，验证 480，inline/crossline 各占一半。
- 空间保护带违规：0；训练/验证源平面重叠：0。
- 训练：120 轮，最佳模型为第 119 轮，验证损失 0.544230。
- 四井 inline 综合相关性：0.613888 -> 0.740524。
- 四井 crossline 综合相关性：0.588366 -> 0.708522。
- 频谱 L1：inline 0.084037，crossline 0.094343。
- 真实残差相位分数：inline 0.649416，crossline 0.616763。
- 0-22 Hz 低频保持：Correlation 1.0，NRMSE 0。

详细评价见 `figures/预测评价/phase18_final_analysis.txt`。
