高频残差预测偏置修复方案
================================================================================

问题描述
--------
训练策略：输入窄频带地震，标签为高频残差（宽频带 - 窄频带），预测后加回窄频带
得到宽频带结果。
观察到现象：预测结果存在幅度基线偏置，整体偏负。


根本原因分析
------------
1. 高通滤波加在 loss 计算之前，会截断低频部分的梯度回传，网络对低频输出
   没有约束压力，长期训练后低频偏置不会消失，只是被掩盖。

2. 高频残差标签在物理上应均值为零（正负对称），若归一化方式导致样本与标签
   均值不匹配，网络会学到系统性偏置。

验证方法：
   print(label_residual.mean())   # 应接近 0
   print(pred_residual.mean())    # 观察预测均值偏移量


修复方案（推荐组合）
--------------------

【第一步】输出层结构修改——强制零均值输出（治本）

在网络输出层之后，推理和训练均生效，强制每个样本的输出均值为零：

    class ResidualHead(nn.Module):
        def forward(self, x):
            out = self.conv_out(x)
            # 强制每个 patch 的输出均值为 0，物理上高频残差均值本应为零
            out = out - out.mean(dim=(-2, -1), keepdim=True)
            return out

【第二步】损失函数中加入均值约束（从优化目标层面消除偏置）

    def residual_loss(pred, label):
        loss_main = F.l1_loss(pred, label)

        # 强制预测残差均值趋近于 0
        loss_mean = torch.abs(pred.mean(dim=(-2, -1))).mean()

        return loss_main + 0.1 * loss_mean

权重 0.1 可根据验证集表现调整，建议范围 0.05～0.2。

【第三步】高通滤波移至推理阶段作为后处理兜底（不放在 loss 计算之前）

训练时：不加高通滤波，保持梯度完整回传，让网络真正学会不产生低频偏置。
推理时：对预测残差做高通滤波，作为保险措施。

    # 训练阶段
    pred_residual = model(x)                          # 输出层已强制零均值
    loss = residual_loss(pred_residual, label_residual)

    # 推理阶段
    pred_residual = model(x)
    pred_residual_clean = highpass_filter(pred_residual)   # 后处理兜底
    output = narrow_band_input + pred_residual_clean


各方案对比
----------
方案                          消除偏置    是否治本    实现难度
--------------------------------------------------------------
loss 前加高通滤波（原做法）    表面上是    否          低
loss 里加均值约束              是          是          低
输出层减均值（结构修改）       是          是          低
推理阶段高通滤波（后处理）     部分        否          低
--------------------------------------------------------------
推荐组合：输出层减均值 + loss 均值约束 + 推理阶段高通滤波兜底


实施优先级
----------
1. 先加输出层零均值（改动最小，立即生效）
2. 再在 loss 里加均值约束项
3. 把原来 loss 前的高通滤波挪到推理后处理
4. 重新训练，对比 pred_residual.mean() 是否收敛至接近 0
