# 22 Context-Masked Calibration

本实验使用连续 `256 x 256` F3窄频上下文，宽频残差监督严格限制在井周32道。

## 数据条件

- 四折留一井，保护区与21号一致。
- 每折三口标定井提供 `inline +/-8` 个平面。
- 每个样本只在井周32个crossline保存宽频残差标签。
- 标签区外为零，另存二值监督掩码。
- 留出井宽频数据仅在checkpoint锁定后用于评价。

## 训练

- 公共预训练模型与21号完全相同，按SHA复用。
- 四折微调均为100轮、每轮32步。
- 局部残差、重建、相关性和相位损失只计算掩码内32道。
- 低频泄漏约束作用于完整预测上下文。

## 结果

- 样本输入从32道扩展为连续256道，构造背景显示问题得到解决。
- Inline direct correlation: `0.610574`，21号为 `0.623633`。
- Crossline direct correlation: `0.588425`，21号为 `0.596170`。
- Inline residual correlation: `0.171718`。
- Crossline residual correlation: `0.207868`。
- Direct不低于低通基线：`3/8`。
- 预声明成功：`False`。

完整上下文改善了样本几何表达，但32道监督对完整输出的约束不足，实际预测效果低于21号。
