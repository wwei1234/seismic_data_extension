# 19_no_wide_supervision

本实验禁止使用 F3 实际宽频数据参与训练、验证、调参和模型选择。

训练分为：

1. 使用 F3 可获得窄频数据进行进一步降频恢复自监督预训练。
2. 使用 16 号测井约束合成残差样本进行高频残差监督训练。

模型锁定后才允许读取 F3 原始参考进行四井 inline/crossline 一次性盲评。

设计说明：`../docs/20_19号实验改进思路.txt`

## 已完成流程

- F3 窄频自监督预训练：40 轮。
- 测井约束合成残差监督训练：200 轮。
- 最佳模型仅按合成验证集损失选择，最佳损失为 0.135759。
- 锁定模型 SHA256：
  `fc272fed9809e1b684d4a1b01b79f1b38e86afdca8913d4824d2a6c3c6bf5f65`
- 锁定后完成四口井 inline 244/362/442/722 与 crossline
  336/387/848/1007 的一次性盲评。

## 结果结论

该方案没有使用 F3 宽频数据参与训练、验证、调参或模型选择，数据边界符合要求。
预测结果在 35-80 Hz 生成了明显能量，频谱 L1 相比低通基线有所下降；但新增高频与
实际宽频残差的相位和波形相关性接近零，导致全频相关性反而低于低通输入。因此本轮只能
证明无泄露条件下实现了频谱能量扩展，不能证明恢复了正确的高频地质信息。
