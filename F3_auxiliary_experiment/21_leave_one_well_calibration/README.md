# 21_leave_one_well_calibration

四折留一井局部宽频标定实验。公共预训练不使用 F3 实际宽频目标；每折只使用另外三口井附近
`inline ±8、crossline ±16` 的局部宽频窗口微调，并对完全留出的第四口井 inline/crossline
进行锁定后评价。18 号模型权重不参与初始化或训练。

## 最终结果

- 公共预训练最佳轮次：297；
- 公共预训练 F3 相关性/相位：0.782307 / 0.786603；
- 四折均从同一公共 checkpoint 初始化，并在第 87 轮锁定；
- inline：相关性 0.625812 -> 0.623633，高频残差相关性 0.192604，相位 0.267332；
- crossline：相关性 0.587083 -> 0.596170，高频残差相关性 0.214291，相位 0.296082；
- 直接重组优于残差高通重组；
- 8 个留出剖面中 4 个相关性不低于低通基线。

本实验显著优于 20 号无宽频监督方案的高频相关性和相位，但未同时满足 inline、crossline
整体相关性均超过基线及至少 3/4 留出井稳定改善的预设标准，因此判定为部分成功、未完全达标。
